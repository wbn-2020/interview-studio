# 材料更正知识影响契约

版本：v1.0 · 2026-11-12。状态：静态检查通过待服务器验收，适用S8第二十七批。更正原文规则承接[固定摘录更正契约](固定材料摘录更正契约.md)，实际实现、四组独立静态复核及构建证据维护在[开发记录](../开发记录/开发阶段与进度.md)；下列服务器场景全部未执行。

## 1. 真实根与准入

材料正文仍不可变，用户先保存新摘录，再明确声明旧新更正。V74声明是唯一真实根，V75只保存它造成的实际知识采用影响，不伪造知识发布版或准备事件，不回填过去根。两端原文、许可修订、V73事件、Manifest／hash／scope及旧回执保持。

原owner写锁内先核两端及声明条件，再以`hasUnsupportedReferences(..., true)`仅豁免合法知识ADOPTED；其他直接材料采用、准备／关系／审阅本地绑定及坏身份仍拒绝。用`MaterialKnowledgeAdoptions.collect`完整证明实际知识闭包及原清单摘要，200知识版／500边／2500原始登记预算沿用，超限或缺史整体失败，不返回或保存截断影响。

对所有可达知识对象检查原始历史出口。第二十七批允许`memory_card_source / memory_attempt_knowledge_source / memory_source_history_knowledge_reference / standard_review_evidence`四类出口由既有钩子及读取守卫承接，AI制卡在当批仍阻塞；第二十八批的限定扩展见[材料更正AI制卡出口契约](材料更正AI制卡出口契约.md)。题目、准备、关系、训练、白板、面试材料、来源问答、今日安排等其他原始出口仍阻塞；`memory_card_concept`仍保守阻塞，不将组织关联等同于内容派生。前端预览、父对象归档或今日状态不作为放行依据。

## 2. 影响身份与事务

V75独立`material_knowledge_impact`的每行固定真实声明、来源域／身份、原任务、采用目标确切版、深度、真实父影响及根时间。第一跳来源为根的旧材料摘录，知识版号／标题字段均null；后代来源为真实知识item／version／number／title。目标及处理目标均须有本人真实知识版，第一跳和后代分别绑定原始采用来源与决定；父身份限定同owner、根及真实知识路径。

复用已完整证明的闭包，按深度先父后子持久化，每条实际采用边只保存一次。允许循环／菱形的不同真实版本，后续人工版按采用版下限保守纳入，不声称正文全部复制自旧材料。只承诺一条真实、稳定、最短发现父路径，不声称该路径穷尽全部依赖或与其他根的同层平局顺序完全相同。

在插入本次声明之前，以服务器原始时间核两端生命周期时间及`latestFrozenAt`，要求晚于已有AI任务／回忆开始／评分及知识、准备、材料根冻结点；时钟冲突拒绝，不自动推进时间。先插真实根，再逐条插影响，插入后调用既有Memory与Reviewed知识上游变更钩子；任一失败使声明、全部影响、卡片／审阅失效及回执整体回滚。S26旧根当时不允许采用，不补写不存在的影响。

## 3. 当前与历史资格

知识`pending`纳入未处理材料影响；`changedAfter`纳入全部材料影响，即使人工处理也保留冻结后的变化事实。均按真实采用目标版号≤当前读取的固定知识版判断。Memory当前来源及评分时固定卡版采用相同范围；三类上游影响身份互斥，同ID跨类出现即拒绝，不因另类已处理而隐藏冲突。

每条影响通过真实身份使受影响回忆卡待复核、暂停排程及失效当前尝试；受审知识依据追加原采用版范围的上游变更代次。历史评分继续显示原条件及上游变化，不改写原评分，不把读取记作复习。新卡、审阅、知识来源及AI当前资格沿共享守卫检查。

人工处理只关闭该影响的pending，不处理其后代，不恢复旧评分、审阅、任务清单、授权或卡片排程。卡片仍需用户显式来源复核与排程恢复。已更正旧材料的祖先AI资格仍受S26守卫拒绝；即使保留当前或发布更新并处理，也可能不能继续AI使用，须另行建立真实的新依据，不能忽略旧祖先或自动改指替代摘录。本批不实现依据重建。

## 4. 目录、详情与处理

新增四个操作，沿登录、本人、资料模块及独立训练访问规则，响应`no-store`，只读事务REPEATABLE_READ／20秒，SELECT显式5秒：

- `GET /api/v1/lifecycle/material-excerpts/{itemId}/knowledge-impacts`：确切旧摘录作为根的影响目录。
- `GET /api/v1/lifecycle/knowledge/{itemId}/material-impacts`：确切目标知识的影响目录。
- `GET /api/v1/lifecycle/material-knowledge-impacts/{impactId}`：真实影响和一条父路径的元数据，不返回正文。
- `POST /api/v1/lifecycle/knowledge/{itemId}/material-impacts/{impactId}/resolve`：显式处理单条影响，200返回更新后的原Impact。

目录必填`state=PENDING|ALL`，`limit`默认20且只接受1–20，`cursor`固定`owner~context~itemId~state~UTC微秒时间~impactId`；按createdAt降序、id降序，不接受未知／重复／空参数。详情和处理不接受查询参数，读取不重建或补写影响。

公开类型保持既有Correction State4／Statement7、Knowledge Impact及准备影响形状。新Source5为`domain / itemId / versionId / versionNumber / title`，域为`MATERIAL_EXCERPT|KNOWLEDGE`，材料后三项明确null。Impact13为`id / revision / correction(Statement7) / source(Source5) / taskId / targetItemId / targetTitle / targetVersionId / targetVersionNumber / depth / parentImpactId / createdAt / resolution`。Page5为`context / itemId / state / items / nextCursor`，context同两类来源域。

处理沿既有Resolve6与Resolution5：影响revision0→1、目标metadata revision与确切发布版CAS、无未发布草稿；KEEP_CURRENT保留当前并说明理由，PUBLISHED_UPDATE须晚于原采用且原始正文确已改变，ARCHIVED须先归档。严格JSON最多16384bytes，拒绝重复／未知字段、错误类型及不明确确认。原键恢复不重查目标今日资格，资料启用及训练访问仍为回执前守卫；同键异请求仍冲突。

## 5. 界面与发布

材料详情和知识编辑器提供主动展开的独立影响面板，选择待处理／全部、分页、逐次查看真实上一跳及导航原任务／确切版本。只有知识目标侧可以明确选择、重读当前发布版、填写理由并处理，不在浏览或导航时自动确认。

新面板接入草稿离开守卫及命令互斥。隐藏、会话或训练访问换代清目录和可见原文，拒绝迟到响应；未决命令保留原路径、键及载荷供主动恢复。更正页面同步解释受支持知识链例外和其他出口限制，不宣称完整删除影响清单。

服务器须在V74后显式应用并核验V75，再发布配套前后端；新旧影响表的读取口必须与写入一起更新。无新依赖或配置键，本机不执行迁移、不启动应用或调用真实模型。
