# 材料摘录直接引用预览契约

版本：v1.1 · 2026-11-12。状态：代码完成待验证；独立静态复核、后端打包与正式业务入口专项检查通过，完整前端本批构建失败且参考界面输入随后发生变化，尚无当前整仓构建通过证据。适用 S8 第十二批，只读展示已经登记的直接摘录绑定，为材料生命周期接入提供可核对入口；实际进度和证据见[开发记录](../开发记录/开发阶段与进度.md)。

## 1. 业务边界

用户打开一条已保存摘录，主动选择引用分类，查看其直接关联的准备版本、AI 任务、正式关系证据或标准审阅修订。摘录以自身 ID 为根，不用附件 ID 代替同一附件下的不同摘录。

目录只读取元数据，不读取目标正文、JSON 快照、清单、候选、答案、引文或私人路径，不调用模型或解析器。它不是完整删除清单，不判断材料外发资格、审阅资格或成长结论，不表示某任务已经发送、收费、成功、采用或人工核实。

本批不开放归档、恢复、用途撤回、删除或清除命令，不改 `MaterialAiExcerpt`、Manifest、hash、旧回执或现有来源当前性。材料到事实／表达／知识／卡片的间接传播和在途授权守卫须在后续生命周期批次同时接通。

## 2. 九类已登记绑定

| kind | 固定绑定 | 条目身份与范围 |
|---|---|---|
| `PREPARATION_VERSIONS` | `preparation_material_reference` | 确切准备版本，保留当前／历史指针及对象当前归档状态。 |
| `AI_KNOWLEDGE_INPUTS` | `ai_material_draft_source`，用途 `KNOWLEDGE_DRAFT` | 原任务元数据，不限是否成功或采用。 |
| `AI_QUESTION_INPUTS` | 同表，用途 `QUESTION_DRAFT` | 原任务元数据，不等同题目采用来源。 |
| `AI_MATERIAL_QA_INPUTS` | `ai_material_qa_source`，用途 `MATERIAL_QA` | 已登记的资料问答任务。 |
| `AI_FACT_INPUTS` | `ai_fact_draft_material`，用途 `FACT_DRAFT` | 资料事实候选任务，不等同已核实事实。 |
| `AI_RELATION_INPUTS` | `ai_relation_evidence_material`，用途 `RELATION_DRAFT` | 资料关系候选任务，不等同正式关系。 |
| `AI_SOURCE_QA_INPUTS` | `ai_source_qa_source`，域 `MATERIAL_EXCERPT`，用途 `SOURCE_QA` | 同任务同摘录合并为一条任务元数据，不加载选区。 |
| `RELATION_EVIDENCE` | `knowledge_relation_evidence_material` | 每条追加式证据记录，保留原关系及端点身份；正式边移除仍保留历史证据。 |
| `STANDARD_REVIEW_EVIDENCE` | `standard_review_evidence`，依据 `MATERIAL_EXCERPT` | 每个审阅 ID／修订合并为一条；同一修订多个证据不重复展示，历史修订不丢失。 |

仅有主题、一般结构关系、训练快照或经准备／知识派生的间接关系不在本批查询范围。各分类独立分页，空页不表示其他分类或间接内容没有影响。

## 3. 读取与分页

`GET /api/v1/materials/excerpts/{id}/references?kind=&cursor=&limit=20`

- 登录、owner、资料模块启用及普通独立训练资料守卫保持；不增加豁免。返回 `Cache-Control: no-store`。
- `id` 为标准小写 UUID。`kind` 必填且严格属于上表；`limit` 只接受十进制 1–20，缺省20。拒绝未知、重复、空查询参数。
- 同一只读 REPEATABLE_READ 事务先核根摘录归属及固定附件关联，再读取所选分类；不以磁盘或解析器可用性决定数据库摘录是否存在，不执行恢复或写入。
- 按 `(referenceId,referenceRevision)` 升序，取 `limit+1` 判断后页。游标为 `excerptId~kind~referenceId~referenceRevision`，最多160字符，绑定根与分类；UUID 和修订均严格校验，修订范围 0–9007199254740991，标准审阅之外须为0。翻页不是跨请求冻结快照，刷新可见新登记项。
- 已有历史修订、归档准备及移除关系不被当前状态过滤。SQL 故障继续返回错误，不伪装为空目录。

## 4. 响应形状

新增封闭必填形状，所有可空字段也保留字段名：

`MaterialReferenceSource6={excerptId,attachmentId,origin,runId,segmentId,createdAt}`。MANUAL 的 runId／segmentId 为null，PARSED 保留固定原解析身份；不返回摘录正文、定位、SHA或文件名。

`MaterialReferenceEntry12={referenceId,referenceRevision,targetKind,targetId,targetVersionId,targetVersionNumber,targetRevision,status,targetCurrent,anchorItemId,otherItemId,anchorVersionId}`。

- 准备：`referenceId=固定版本ID`，`targetKind=PREPARATION`，targetId为稳定对象，targetVersionId／Number为固定版本；targetRevision和三个锚点为null，referenceRevision=0。status为对象当前ACTIVE／ARCHIVED，targetCurrent只比较当前正文版指针。
- AI：`referenceId=targetId=任务ID`，`targetKind=AI_TASK`，referenceRevision=0；版本／修订／锚点为null，targetCurrent=true表示固定任务身份，status沿任务原状态。
- 关系证据：referenceId为证据ID，`targetKind=RELATION`，targetId为原关系ID，referenceRevision=0；版本／修订和anchorVersionId为null，anchorItemId／otherItemId为原端点。status为ACTIVE／REMOVED，targetCurrent表示同owner、同关系ID及端点／类型的正式边是否仍存在，不表示证据被核实。
- 标准审阅：`referenceId=targetId=审阅ID`，`targetKind=STANDARD_REVIEW`，referenceRevision=targetRevision=固定审阅修订；目标正文版字段为null，anchorItemId／anchorVersionId为所属确切题目／题目版，otherItemId为null。status为审阅当前ACTIVE／WITHDRAWN，targetCurrent只比较审阅当前修订指针，不能作为资格结论。

`MaterialReferencePage5={kind,coverage,source,items,nextCursor}`，coverage固定`REGISTERED_DIRECT_ONLY`，items至多limit条；无后页时nextCursor为null。

## 5. 前端与导航

在已确认摘录详情中提供主动展开的“已登记直接引用”入口；展开后选择分类才读取。按会话、资料访问代次、摘录及分类隔离响应；隐藏、失权、切换根／分类时清除旧页及迟到响应，保留上一个请求参数以便明确重试，不自动切换权限或发起模型调用。

返回的分类、Source6、Entry12、游标、顺序与数量须核对，异常不显示为合法目录。AI按分类确定用途标签，拒绝未知状态；不把成功任务叫作内容采用。

Source6还须与父摘录详情已确认的origin、解析身份和保存时间逐项匹配；不只核摘录和附件ID。上层`v-show`隐藏、文档不可见或收起时清旧页，不自动恢复读取。

准备进入确切历史版，AI进入原任务；关系仅进入原源端点，再按显示的关系／证据ID手选核对；标准审阅进入所属题目确切版，再按审阅ID／修订手选历史。不声称自动定位关系证据或审阅修订。跳转沿原导航保稿及资料守卫，不自动查看正文、揭示参考、处理影响或恢复排程。

## 7. 实施与静态证据边界

累计OpenAPI 7.41.0新增一个GET路径、五个schema；九分类和Source6／Entry12／Page5与生成类型配套。V72仅增加三项反查索引，V1–V71原文保持，未执行迁移。400／404复用既有`INVALID_REQUEST`／`MATERIAL_NOT_FOUND`，成功响应保持`no-store`及既有资料守卫。

后端388 Java打包成功；正式业务入口专项类型检查及Vite构建成功。完整前端构建时参考界面缺四组件而退出2，随后其源码新增文件，旧失败日志不作为当前整仓输入的最终结论。专项制品只覆盖`index.html`业务入口，不作为完整前端部署包。真实SQL、MyBatis映射、HTTP、权限竞争、导航、视觉和性能均未执行，MREF-01–10保持未验收；材料生命周期命令及间接来源传播仍未实施。
