# 题库与学习路线接口与数据契约

日期／版本：2026-11-06 · v0.2。状态：S4 第一批实施契约，未运行验收。覆盖 BANK-01–04／06 的手工题库、题单与学习路线；训练会话、回答／图文提交、暂停和辅助守卫按[第二批契约](训练会话与作答接口与数据契约.md)衔接，不将题库目录本身视为模拟面试。实际进度见[开发记录](../开发记录/开发阶段与进度.md)。

## 1. 业务边界

题目身份保持稳定，题干、条件与参考标准成组生成不可变版本。创建、修改正文、整理状态分别处理；停用和收藏不改正文版本。所有手工标准固定为 PERSONAL_UNREVIEWED，用户不能通过请求字段自行宣称已经专业审核。AI 及导入候选接入遵循同一结构，但本批只接收用户自建内容。

普通列表／详情／历史接口不返回参考答案和检查点。用户显式打开确切版本的参考，先在同一 owner 事务记录 REFERENCE_VIEW 事件，再返回参考；保存自建版本记录 AUTHORED，二者分开。它们是可追溯的曝光背景，不认证用户实际阅读，也不据此判断能力。题目编辑器读取既有参考同样走该显式操作。S4 第二批将上述入口及回执重放统一纳入在训辅助守卫，仍待服务器验收；既往曝光不能代替本场辅助条件。

题单复用题目确切版本，保存顺序和练习目的；路线在同一结构上增加前置步骤及检查点。列表顺序不暗示依赖，依赖必须显式填写且不能自环／成环。检查点是可编辑的学习目标，本批不伪造完成率或以勾选关闭训练任务。

## 2. 对象及容量

沿用小写 UUID、UTC 微秒、JS 安全 revision、owner 归属、1 MiB JSON 请求和 2 MiB 回执。正文保留原文，不通过 trim 改写证据。可选文本缺省规范化为空串，可选列表缺省空数组；必填值、未知字段、数字枚举、小数截整和标量强制转换拒绝。

`QuestionInput={title,prompt,conditions,technology,scenario,type,difficulty,dimensions,topicIds,knowledgeLinks,tags,source,referenceAnswer,checkpoints}`。

| 字段 | 规则 |
|---|---|
| title／prompt | 标题非空≤200；题干非空≤10000，Markdown 代码仅展示 |
| conditions／technology／scenario | 分别≤5000／2000／2000；保存题目适用条件与技术版本，不代表真实发生概率 |
| type | EXPLAIN、CODE_READING、DEBUG、PROJECT、TRADEOFF、SYSTEM_DESIGN、BEHAVIOR |
| difficulty | null 或整数 1–5，明确为个人难度标记 |
| dimensions | 1–6 个不同值：EXPLAIN、DEBUG、TRADEOFF、OWNERSHIP、COMMUNICATION、OTHER |
| topicIds | ≤20 个不同知识主题 ID；当前题目主题用于筛选，版本保留当时的主题 ID |
| knowledgeLinks | ≤20 个 `{itemId,versionId}`，可关联 NOTE／CONCEPT 确切发布版本；新增必须当前 ACTIVE，已有旧引用可以保留并显示状态 |
| tags | ≤20 个不同的非空标签，每项≤40 |
| source | `{title,url,note}`，≤200／2000／5000；url 为空或 http(s)，不抓取 URL；来源为用户记录 |
| referenceAnswer | ≤20000，可为空，作为个人参考，不能伪装受审标准 |
| checkpoints | ≤30 个不同 `{id,text}`，ID 在该题内稳定，text 非空≤500；与题干成组版本化 |

`QuestionPrompt` 是 QuestionInput 去掉 referenceAnswer/checkpoints 的结构。`QuestionVersion={id,number,createdAt,content:QuestionPrompt,standardStatus:PERSONAL_UNREVIEWED,hasReference}`，hasReference 表示有参考文本或检查点。`Question={id,status:ACTIVE|ARCHIVED,revision,favorite,createdAt,updatedAt,currentVersion,knowledgeReferences}`。`KnowledgeReference={itemId,versionId,title,number,state:CURRENT|SUPERSEDED|ARCHIVED}`，标题取确切版本，不取当前草稿标题。

`QuestionSummary={id,title,type,difficulty,status,revision,favorite,versionId,versionNumber,standardStatus,topicIds,updatedAt}`。`VersionSummary={id,number,title,createdAt}`。`Reference={questionId,versionId,standardStatus,referenceAnswer,checkpoints,exposureId,recordedAt}`。`Exposure={id,questionId,versionId,kind:AUTHORED|REFERENCE_VIEW,createdAt}`；来源事件保留，后续历史曝光查询不能把 AUTHORED 误当成系统观察到用户阅读。

`CollectionInput={title,purpose,steps}`。`CollectionKind=LIST|ROUTE` 创建后不变；title 非空≤200，purpose≤5000；steps≤50，允许先保存空集合。`Step={id,questionId,questionVersionId,purpose,dependsOn,checkpoint}`，purpose／checkpoint 各≤1000；steps 数组决定顺序，步骤 ID 在集合内稳定；同题可出现在多个集合，同集合不重复同一个 questionId。LIST 的 dependsOn 必须为空；ROUTE 每步≤49 个不重复依赖，必须指向同一版本中的其他步骤，检查 DAG，不按显示顺序推断完成条件。

`CollectionVersion={id,number,createdAt,content:CollectionInput}`。`Collection={id,kind,status,revision,createdAt,updatedAt,currentVersion,questionReferences}`。`QuestionReference={stepId,questionId,versionId,title,number,state:CURRENT|SUPERSEDED|ARCHIVED}`。`CollectionSummary={id,kind,title,status,revision,versionId,versionNumber,stepCount,updatedAt}`。首次添加／更换题目引用要求 ACTIVE 当前版本；保存时只允许保留服务端上一版本已存在的确切引用，旧题或停用题显示警告，不静默替换新题干。后续开始训练须单独预览实际选用版本。

## 3. API 契约

均使用 `/api/v1/bank` 前缀。所有写入要求 Session、CSRF、Idempotency-Key；更改已有对象还要求 expectedRevision。GET 不产生曝光事件，也不读取隐藏参考。列表 limit 默认 20、1–50，ID 正序 cursor UUID；历史版本 number 倒序 before；曝光按 createdAt／id 倒序，before 为 Instant~UUID。q 是保存标题的字面筛选≤100，scene 是场景字面筛选≤100，不能称全文检索。

| 方法／路径 | 请求与响应 |
|---|---|
| GET `/questions?status=ACTIVE&q=&type=&difficulty=&dimension=&topicId=&knowledgeId=&scene=&favorite=&cursor=&limit=20` | `{items:QuestionSummary[],nextCursor}`，所有筛选作用于当前版本 |
| POST `/questions` | QuestionInput → 201 Question；插入首版及 AUTHORED |
| GET `/questions/{id}` | Question，包含当前确切知识引用状态 |
| PUT `/questions/{id}` | `{expectedRevision,content:QuestionInput}` → Question，形成新版本及 AUTHORED |
| POST `/questions/{id}/archive`、`/restore` | `{expectedRevision}` → Question；停用仍可读历史 |
| PUT `/questions/{id}/favorite` | `{expectedRevision,favorite}` → Question，不增加正文版本 |
| GET `/questions/{id}/versions?before=&limit=20` | `{items:VersionSummary[],nextCursor}` |
| GET `/questions/{id}/versions/{versionId}` | QuestionVersion，固定题干且不带参考正文 |
| POST `/questions/{id}/versions/{versionId}/reference` | `{}` → Reference；追加曝光及回执同事务，同键重试不重复事件；不是只读 preview |
| GET `/questions/{id}/exposures?before=&limit=20` | `{items:Exposure[],nextCursor}` |
| GET `/collections?kind=&status=ACTIVE&q=&cursor=&limit=20` | `{items:CollectionSummary[],nextCursor}` |
| POST `/collections` | `{kind,content:CollectionInput}` → 201 Collection |
| GET `/collections/{id}` | Collection，包含当前引用版本状态 |
| PUT `/collections/{id}` | `{expectedRevision,content:CollectionInput}` → Collection，新版本保留完整步骤／依赖 |
| POST `/collections/{id}/archive`、`/restore` | `{expectedRevision}` → Collection |
| GET `/collections/{id}/versions?before=&limit=20` | `{items:VersionSummary[],nextCursor}` |
| GET `/collections/{id}/versions/{versionId}` | CollectionVersion；旧步骤按当时版本阅读 |

总计 19 操作。所有写入在 IdempotencyService 的 owner 锁内按命令类型校验来源、CAS 与版本上限，并原子保存相应对象／版本／关系／曝光／回执。参考查看只追加事件，不要求 expectedRevision，也不推进题目修订号；其幂等操作标识包含确切题目和版本路径。读详情使用一致快照。无权与不存在统一 404 QUESTION_NOT_FOUND／COLLECTION_NOT_FOUND，不泄漏他人标题；错误另含 INVALID_REQUEST、REVISION_CONFLICT、ITEM_ARCHIVED、SOURCE_UNAVAILABLE、SOURCE_CHANGED、ROUTE_CYCLE、REVISION_LIMIT。冲突保留输入，未知响应使用原请求原键重试。

## 4. 存储和前端

追加 V9 题库迁移与 V10 题单／路线迁移，保留 V1–V8。题目、版本、当时主题、知识引用、考察项、曝光独立存储；集合、版本、确切步骤和依赖独立存储。外键包含 owner＋对象／版本；引用和筛选不能靠无界 JSON 扫描。正文 JSON 只用于已校验固定内容；当前筛选通过版本关系索引及有界查询完成。

前端训练入口增加“题库”“题单与路线”“文字训练”子入口。本批文字训练保留明确的未接入说明；题库与路线提供真实列表／筛选、创建／编辑、停用恢复、历史及确切引用阅读。参考按显式操作返回，不预载到折叠区域；编辑既有题目须先载入参考且记录事件。路线路径先用有序步骤和明确前置选择器表达，无须引入新的图形依赖。

沿用 Vue Query 的会话代次、useCommand 原键恢复、dirty／locked 离开守卫。纯切历史不卸载同一编辑器；迟到选择／请求不能修改已锁定、已卸载或会话更换后的表单。表单未提交内容保留内存，刷新会丢失尚未保存的输入；不得称作持久草稿。当前模板不注入示例题目或合成学习完成状态。

## 5. 验证及下一批边界

本地只做 DTO／OpenAPI、Mapper／DDL、代码独立复核及类型／构建；不新增依赖，不编写或运行单元测试，不启动服务。服务器验证过滤／权限、成组版本、原键重放、冲突保稿、曝光与版本匹配、停用引用提示、路线成环／不存在依赖拒绝、历史与窄屏／键盘交互。

S4 第二批契约规定训练会话、题实例、答案服务器草稿与不可变提交、时间／未观察区间、辅助暴露及历史读取守卫、结束清单和系统设计图文快照。辅助守卫覆盖参考回执重放和浏览器已缓存内容，不能仅放在首次写入的业务 action 中；代码已构建，运行仍待验。第一批的曝光账本提供先前背景，不能代替上述进行中会话规则。学习路线的日期安排及能力／进度判断仍依 S7，AI 出题、追问与确切父答绑定依 S5。
