# 训练会话与作答接口与数据契约

日期：2026-11-06。版本：v1.1。状态：S4 第二批实施契约，S5 第七批追加背景当前状态；代码、数据库与服务器验收分别记录于[开发进度](../开发记录/开发阶段与进度.md)。关联 TRN-01–08、ARCH-01–04；AI 追问／评价在 S5，独立复练在 S6。

## 业务与状态

- 一次训练固定模式、题目版本、目标／项目／已确认事实版本、阶段和时间预算。无目标、无材料、无 AI 均可开始。创建得到 DRAFT，预览确认后 start；DRAFT → RUNNING ↔ PAUSED → ENDED，DRAFT 可直接结束。结束不能重开。
- 每个 owner 同时最多一场 RUNNING／PAUSED 训练，工作区锁内检查。可保留多个预览草案和历史。开始前刷新并确认来源提示；新建仅允许当前 ACTIVE 题版本，题单来源可保留其确切旧题版本并提示，不重新排序路线依赖，不把路线检查点当题干发送。
- 模式为 LEARNING／FOCUSED／MOCK。学习模式允许资料；专项与模拟默认先答。模式仅说明练习条件，不宣称能监测外部网页或证明没有辅助。模拟结束前不自动展示参考。默认专项 1 主问、模拟 3 主问；本批支持 1–20 主问、最多 8 个自定义阶段、0–2 次后续追问额度（S5 才执行）、反馈时机 AFTER_ANSWER／AFTER_SESSION。时间预算可空或 1–240 分钟，时间到只提示。
- 题实例状态 PENDING／ANSWERED／SKIPPED 与草稿分开。保存草稿不自动提交；提交内容必须来自此次明确发送的文字与图，产生不可变 AnswerRevision，并清空已消费草稿；修改已提交答案仍是同题的新修订。跳过保留草稿；unskip 仅对 SKIPPED 恢复，已有提交仍标 ANSWERED。
- 暂停可读取和保存草稿，不能提交／跳过；结束后草稿与提交均只读，支持下载文字和图 JSON 另存。结束前展示服务器清单，明确未保存本地输入尚未计入清单；结束事务固定已答／跳过／未答和未提交草稿数量。

## 保存、时间与辅助

- 会话 revision 保护开始、暂停、恢复、结束、辅助授权；题实例 revision 独立保护草稿、提交和跳过。题写入同时验证 expectedSessionRevision 和 expectedRevision。心跳不递增这两个 revision。所有修改使用原幂等键、owner 锁及同事务回执。
- 会话响应另带 checklistToken（有序题 ID／修订摘要）；结束必须传回用户已审阅的 expectedChecklistToken。题目在其他标签保存或提交后，结束返回 CHECKLIST_CHANGED，重新读取并确认清单；不能仅依赖未变化的会话 revision。
- 草稿在服务器持久化；浏览器只在收到保存回执后显示已保存。未知结果保留原请求和键；刷新后以服务器草稿、最新提交及状态恢复，不声称未发送的按键可恢复。前端采用显式保存和提交，不持久化个人答案到 localStorage。
- 编辑基线与最新服务器题副本分别保留。跨标签结束时，结束草稿、最近提交和下载依据与会话题目修订核对过的服务器副本；尚未取得该修订时显示待核对，不能把旧编辑基线标为结束记录。页面内未保存输入另行保留，收起对照面板不丢弃最新服务器副本。
- RUNNING 时可见训练页每 20 秒发 pulse。相邻服务器接收点相差不超过 45 秒的区间计 observedSeconds，否则整段计 unobservedSeconds；暂停区间另计 pausedSeconds。启动、恢复建立接收点；暂停／结束结算；只读响应将尚未被观察的尾段显示为未知，不虚增已观察时间。该时间是页面连接观察，不代表专注度或真实键盘活动。
- 所有辅助确认是不可撤销事件。LEARNING 从开始按学习条件记录；其他模式经显式确认 MATERIAL_ACCESS 后允许此次训练剩余阶段查阅站内资料，之后提交为 ASSISTED。事件代表授权查看的条件，不伪称已经读完某篇资料。提交固定当时条件、辅助事件截止和既往题目曝光；后来的资料查看不倒改原答。
- 专项／模拟的资料守卫覆盖题库参考、知识正文／搜索／星图／白板、准备材料、附件、历史训练，以及可能返回正文的写入回执；当前训练固定目标与事实是题目条件，可正常读。服务端在回执重放前重新检查动态守卫；前端在路由显示前核对当前训练、停止资料读取并使缓存失效，保留查询观察者和未保存表单，恢复授权后重新取数；跨标签通知或窗口重新激活时重新遮挡核对，包括挂载到页面外的弹层。无法撤回用户此前已看过、复制或在外部打开的资料，界面明确该限制。
- 查看当前题参考经专用 POST，专项／模拟要求已授权辅助（若只看已提交参考也影响之后答案）；结束后允许。源题的 AUTHORED／REFERENCE_VIEW 是既往曝光，独立于本次辅助。首轮不声称题目未见过。

## 图文与上下文

- 答案文字最长 20,000 字符；图最多 80 节点、160 边。节点包含 UUID、label、description、有限坐标 x/y；边包含 UUID、source／target／label，禁止不存在端点与重复 ID。提交时图非空必须有文字解释，草稿可暂缺说明；约束、容量、异常与取舍写在正文模板。
- 图节点可关联确切 KNOWLEDGE／PROJECT／FACT 版本；新关联在允许资料后校验 owner、种类与版本并存快照标题。学习白板由显式导入操作固定节点／边及来源 revision，必须先确认辅助；不会引用一个随时变化的白板作为答案。导入候选带 importId，服务端同事务保存 owner、会话、白板和修订；首次保存来源必须核对这份凭证，不能仅凭客户端填写的白板编号声明来源。候选允许继续编辑，用户保存／提交后成为草稿／答案。
- 材料快照限 1 目标、1 项目、10 条当前 CONFIRMED 事实；只包含这些显式选中的版本，不自动扩散链接、附件、表达稿或知识正文。开始重验来源状态，来源有改版／归档／撤回时拒绝并要求重建预览，历史不随来源更改。
- 会话详情追加 `contextChecks` 显示原背景当前是否仍可用于新追问；常规读取返回数组，旧幂等回执缺字段时表示尚未核对。原背景、原答与手工训练操作不变；失效背景排除预览、来源代次和 AI 接纳规则统一见[训练背景更正与 AI 使用契约](训练背景更正与AI使用契约.md)。
- 创建请求整体沿用 1 MiB 上限；上下文快照序列化最多 128 KiB；单题内容（草稿／提交含图）最多 192 KiB；会话详情只带题目摘要，逐题读取正文和提交历史，避免幂等回执无限膨胀。每题最多 100 次提交修订、每会话最多 1999 条普通事件并为结束保留一个名额；达限返回明确 422，结束仍可执行。运行和暂停时都提供本地文字／图另存；另存不会标记服务器已保存，用户明确撤销本地修改后才能通过结束确认。

## API 与标识

统一前缀 `/api/v1/training`。UUID、owner、UTC 微秒、严格 JSON、请求上限、幂等键与错误沿用既有契约。响应以 TrainingDtos 和合并 OpenAPI 为机器基线；全部命令带 Idempotency-Key，GET 不改变训练。

| 方法／相对路径 | 行为 |
|---|---|
| GET /sessions?status&cursor&limit | 按 ID 游标列出训练摘要 |
| POST /sessions | 创建固定条件预览；明确题版本和可选 collection 来源 |
| GET /active | 固定对象 `{session: 摘要或 null}`，表示当前 RUNNING／PAUSED 训练 |
| GET /sessions/{id} | 会话配置、固定上下文、题摘要、时间、结束清单 |
| POST /sessions/{id}/start、pause、resume、end | expectedRevision；end 还要求 checklistConfirmed 和 expectedChecklistToken；状态与清单 CAS |
| POST /sessions/{id}/pulse | 空对象；仅 RUNNING 更新观察时间，返回时间摘要 |
| POST /sessions/{id}/assistance | expectedRevision、reason；永久授权本次资料查阅 |
| GET /sessions/{id}/events?before&limit | 倒序事件分页，审计辅助／状态／未知区间 |
| GET /sessions/{id}/questions/{questionId} | 题干快照、草稿、当前最新提交，含 sessionRevision |
| PUT /sessions/{id}/questions/{questionId}/draft | 双 CAS、文字与图；允许 RUNNING／PAUSED |
| POST /sessions/{id}/questions/{questionId}/submit | 双 CAS、文字与图；仅 RUNNING，原子清草稿、写不可变提交与回执 |
| POST /sessions/{id}/questions/{questionId}/skip、unskip | 双 CAS；仅 RUNNING，保留草稿 |
| GET /sessions/{id}/questions/{questionId}/answers?before&limit | 提交修订摘要，不返回参考 |
| GET /sessions/{id}/questions/{questionId}/answers/{answerId} | 确切提交文字／图／辅助条件 |
| POST /sessions/{id}/questions/{questionId}/reference | 空对象，动态辅助守卫及题库曝光，回执重放也重验 |
| POST /sessions/{id}/import-board | boardId、expectedBoardRevision；辅助守卫，固定图候选 |

题实例 questionId 是训练内新标识，sourceQuestionId／sourceVersionId 才是题库来源。collectionId／collectionVersionId 成对可空。创建 questions 包含 sourceQuestionId、sourceVersionId、stage；每题只出现一次。contextLinks 只接受 TARGET／PROJECT／FACT 的确切版本。

409 包含 REVISION_CONFLICT、CHECKLIST_CHANGED、SESSION_STATE_CONFLICT、ACTIVE_SESSION_EXISTS、ASSISTANCE_CONFIRMATION_REQUIRED、SOURCE_CHANGED、IDEMPOTENCY_KEY_REUSED；422 包含 SOURCE_UNAVAILABLE、TRAINING_LIMIT、INVALID_DIAGRAM。404 不泄露其他 owner。任何错误都不得无声覆盖用户输入。历史答案读取在另一场独立训练进行时同样受辅助守卫。

## 数据与事务

V11 追加 training_session、training_question、training_answer、training_event、training_board_import。身份、owner／会话／题目复合外键、顺序唯一和修订上限由数据库约束；配置／上下文／题干／草稿／图内容以有结构验证的 JSON 保存。正式答案与事件仅追加。跨域来源保存确切标识与快照，归档和改版不修改历史；删除与清除属于 S8。

单 owner 工作区锁串行化来源校验、活动会话检查、双 CAS 和写入回执。开始固定既往曝光标记。结束事务读取题清单并冻结摘要，不自动提交草稿。所有动态资料权限检查包括幂等回执路径，不能只放在首次执行 action 内。
