# 全站最近访问契约

版本：v1.0 · 2026-11-11。状态：独立静态复核及前后端构建通过，待服务器验收。适用：[完整产品需求](../需求文档/产品需求文档.md)全局最近访问入口及KNOW-05；进度和实际证据维护在[开发记录](../开发记录/开发阶段与进度.md)。这是本批实施规则，不代表用户逐项确认或服务器验收通过。

## 1. 记录含义与入口

最近访问是回到已打开对象的便捷目录。记录稳定类型、对象ID和服务器最后确认时间，按对象去重；打开入口回到对象当前页面。历史版本、原答、反馈观察和白板修订仍从原模块历史／来源入口查看，本目录不声称恢复上次确切选区、版本或滚动位置。

客户端仅在顶层详情已接纳、当前路由对应对象、页面可见且资料允许时提交一次访问。同组件轮询、自动刷新、引用选择器、搜索命中、模型预览、卡片揭示及单纯列表不记录；取消导航或详情读取失败不记录。重登不重置同一详情的记录机会，创建／保存／提醒确认回执不预填首次详情来触发访问。复盘只有提交复盘标签内的训练详情可见时记录，全场报告接纳可以记录，单题提交分页不另记。访问不是学习、回忆、训练、复练完成或模型上下文记忆，不改变这些状态。

全局侧栏和命令面板进入独立最近访问页面；用户打开页面或主动刷新才读取目录，过滤／翻页按请求代次处理。点击目标通过既有路由保稿与资料守卫，随后原详情再次核对权限；目录可见不代表正文已经获准。

## 2. 类型与稳定身份

| kind | 当前对象入口／目录元数据 |
|---|---|
| KNOWLEDGE | 笔记／概念，knowledge?item；当前发布标题，无发布版用“未发布笔记／概念”，不读取草稿 |
| PREPARATION | 目标／项目／事实／表达，prepare?item；对象类型、当前标题与状态，未核实事实仍是用户材料 |
| MATERIAL | 附件，materials?attachment；文件名、类型和上传状态；资料功能关闭时不展示 |
| QUESTION | 题库题目，bank?item；当前题面标题与状态，不读取参考 |
| COLLECTION | 题单／路线，collections?item；类型、标题与状态 |
| TRAINING | 训练会话，training?item；标题、模式与会话状态；复盘／报告打开同一会话可记为该对象 |
| RECOLLECTION | 面后回忆，recollections?item；当前版本标题、回忆身份与状态 |
| MEMORY_CARD | 回忆卡，memory-cards?item；当前卡片标题、类型与状态，不读取题面／参考或计复习 |
| AI_TASK | 模型任务，ai?item；任务标题、用途与状态，不读取清单／候选或调用模型 |
| BOARD | 脑图／白板，boards?board；类型与当前标题，没有归档状态时用AVAILABLE |
| INTERVIEW | 面试安排，schedule?item；标题与状态，不读取会议地址／URL／备注 |
| PREPARATION_TASK | 普通准备任务，preparation-tasks?item；标题与状态，不读取详情 |
| REPRACTICE | 独立复练，repractice?item；关联会话标题、题型与状态，不读取旧答／回忆基线 |

请求只接受kind与标准小写UUID id；不接受owner、标题、正文、任意地址、路由参数、客户端时间或版本作为权威值。跨表UUID不视为全局同一对象，键为owner＋kind＋id。目录标题／状态读取时从本人对象取得，不在访问表或回执复制，标题变化不产生第二条对象记录。标题保留来源既有数据规则，不用更严格的新输入规则拒绝合法历史值或整页目录。

## 3. 持久化、分页与旧知识兼容

V58仅新增recent_visit表，保存owner_id、target_kind、target_id、visited_at；主键为前三项，owner复合时间／类型／ID索引用于分页，owner外键指向个人工作区。该表是可失效的导航索引，不是训练证据或正式引用；服务在同owner锁内核对真实对象，读取时再次联查本人对象，缺失对象不显示，不跨类型或回退任意地址。

所有访问写入由原IdempotencyService持owner锁，最近目录与知识组织访问时间在同事务更新。旧knowledge visit响应、请求、RECENT过滤及排序保持；V58从现有knowledge_organization.visited_at复制知识访问身份／时间。旧visit和新统一visit均更新两个口径，不能把迁移或全局访问计作知识修改、曝光或学习事件。只读GET不顺带记录访问。

访问时间由服务器生成UTC微秒，更新单对象时间不倒退。同键同请求返回原kind／id／visitedAt，不重新更新时间；同键不同请求拒绝。回执只有元数据，不包含标题或正文。普通资料守卫作用于新recent模块，访问权不会由目录或记录命令自动授予；附件关闭或对象不存在明确拒绝新写入。

GET按visited_at降序、kind与id的ASCII升序，游标是规范UTC时间~kind~UUID，完整包含排序键，限制日期为MySQL可用范围且微秒对齐。每页1–20项、单次最多检查64条访问记录，逐条仅查窄元数据；缺失或资料关闭记录跳过，以最后已检查行生成继续游标，不跳过尚未检查记录。扫描达到上限且未填满页面仍可继续，scanLimited明确说明，不返回全库总数。并发新访问会改变排序，翻页不是固定数据库快照，用户刷新回到最新。

读取编排20秒只读RR事务，新增SELECT显式5秒；禁止读snapshot_json、content_json、题干、参考、草稿、答案、反馈、AI manifest／candidate或附件字节。目录返回前复用普通训练资料守卫；返回检查后的网络窗口与S8最新撤权账本边界继续保留。对象归档不删除记录，目录显示其真实当前状态；恢复和删除传播依S8实施。

## 4. API与前端队列

| 方法／路径 | 请求／响应 |
|---|---|
| GET `/api/v1/recent` | 可选kind、cursor、limit默认20；Page为items／nextCursor／scanLimited，Entry为kind／id／title／subtype／status／visitedAt |
| POST `/api/v1/recent/visits` | 严格kind／id，原Idempotency-Key；返回Visit为kind／id／visitedAt |

前端13类对象统一使用常驻有界内存队列持有最近访问请求与原键，跨页面继续存在，不注册业务草稿／导航锁，不阻塞正式保存或正常离开。知识详情也使用新统一接口，旧知识visit仅保留服务端兼容；本标签知识访问确认后，在同一会话与资料许可代次内刷新原知识目录，保持RECENT读取口径。最多32条不同对象的未确认记录，满额明确提示，不静默覆盖；同对象已排队时不再生成新键。每次最多一个请求，失败保留原请求，用户主动恢复，不按网络故障自动重新发新命令。

队列仅存kind、id、原键和状态，不存标题／正文，不写浏览器存储。登出或会话失效暂停发送，重新登录仅同一owner且资料可用后由用户主动恢复原请求；不同owner清原队列，不向新账号重放。新对象读取可以触发自己的新访问，不能自动重放已有失败队列。写入回执严格核类型、对象和时间；非法／未知回执保留原键，明确4xx失败结束本条，不影响真实详情。浏览器关闭前未确认队列无法在另一实例继续恢复，界面如实提示，不声称磁盘持久恢复。

最近页面对会话、资料状态、页面可见性和请求代次守卫；失权或拒读清目录标题与数据，恢复不自动载入旧页。接收迟到访问回执只核最小元数据，不缓存来源正文。跨标签通知只传“变化”，不传标题／对象正文，不自动查询；用户主动刷新最新目录。当前只增加读取和记录，记录移除／清除归S8，不能把“最近访问清理”当作业务内容删除。
