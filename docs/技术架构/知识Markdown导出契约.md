# 知识 Markdown 导出契约

版本：v0.1 · 2026-11-13。适用：S8第四十一批，DATA-05可阅读导出的首批。状态：**静态检查通过待服务器验收**；浏览器下载、权限竞争及视觉场景尚未在服务器执行。完整文件交换、备份和恢复不由本契约认定完成。

## 1. 业务范围与入口

- 知识详情可以导出当前指针对应的发布版本；即使编辑区存在未保存输入或已保存未发布草稿，也只读取发布版，按钮及确认范围明确标注。
- 版本历史可以导出当前所选的确切发布版本，包括可读的归档知识历史。右侧对照版本、阅读排版与100行分页都不改变导出的版本或全文范围。
- 用户点击导出入口后，面板重新读取既有`GET /api/v1/knowledge/items/{id}/versions/{versionId}`。已有`KnowledgeController.version`／`KnowledgeService.version`负责归属和版本所属对象检查；前端不从编辑器、旧查询缓存或页面片段拼原文。
- 读取成功、版本身份与正文元数据核对后，展示完整文件原文。用户再次点击下载按钮才发起下载；展开、刷新读取、请求完成、恢复权限和切换版本均不自动下载。
- 此能力不更改知识、草稿、版本、关系、复习、AI授权或审阅记录，不新增后端接口、数据库迁移、依赖和OpenAPI字段。

## 2. 文件格式与明确遗漏

编码为UTF-8，MIME为`text/markdown;charset=utf-8`，文件名固定为`wenjie-<知识UUID>-v<版本号>.md`，不从用户标题生成路径。一个文件只承载一个发布版本：

| 元数据字段 | 含义 |
|---|---|
| `export_format` | 固定`wenjie.knowledge-markdown/v1`，仅表示本可读格式 |
| `export_scope` | 固定`selected_published_version` |
| `source_item_id`／`source_version_id` | 来源知识与确切发布版本身份，不能据此授权恢复或覆盖 |
| `version_number`／`title` | 该发布版的版本号与原标题 |
| `version_created_at` | 服务器版本响应中的原发布时间，UTC |
| `exported_at_client` | 浏览器生成此文件的UTC时间，不是服务器时间证明或签名 |

受控YAML frontmatter使用固定字段；字符串按JSON双引号转义，额外编码YAML换行和禁用控制字符。标题中的引号、换行、冒号或类似属性文本不产生新字段。关闭元数据块后，直接接原`body`，不修剪首尾空白、不归一化原换行、不追加标题或结束换行。

正文内部链接（包括`knowledge:`）、Wiki语法、附件和远程图片地址均原样保留。导出不解析执行代码、插件或HTML，不自动获取远程媒体、关联笔记或附件；预览使用文本插值而非HTML。

面板显示范围和遗漏：不包含编辑草稿、其他笔记、附件、主题／关系／布局、AI任务与采用／证据账本、训练历史或复习状态。此文件不是完整备份，也不是完整Obsidian库；不保证站内链接在外部工具可导航，不重建来源资格、审阅状态或原身份。完整导出、批量打包、恢复、Markdown／Obsidian导入、链接映射等继续实施。

## 3. 读取、下载与权限边界

- 两个入口均复用资料访问条件：登录有效、未在检查或挑战资料权限、非资料受限训练、训练访问命令未锁定。知识详情另受编辑命令锁及对象／当前发布指针一致条件限制；历史入口须所选响应身份一致、无读取错误且不在重取。
- 面板开启、重新读取和下载均检查页面与元素可见性。父级`v-show`、`hidden`、`inert`、`aria-hidden`、`visibility`、页签隐藏或组件停用后清除暂存全文并关闭面板；重新可见须用户重新展开读取。
- 对象、版本、版本号、登录代次或训练资料条件变化同样清空。异步响应必须同时匹配读取代次、登录代次、训练访问epoch及确切对象／版本／版本号；卸载或条件变化后的迟到响应不展示、不下载。
- 响应核对UUID、版本号、原标题、完整正文及发布时间类型和边界；身份不符、格式异常、401／403／404、超时等失败不会保留上一次可下载文件，允许用户重新读取。
- 下载前再次比较准备文件时的登录与训练访问epoch及版本身份。文件由用户点击时在浏览器创建Blob及临时对象URL；即使发起下载失败，也安排回收URL。
- 状态只承诺“已向浏览器发起下载”，提示用户检查下载记录和文件内容。系统无法证明用户磁盘已保存，不提供虚构的成功回执或后台下载任务。
- 文件在浏览器内存即时生成，无服务器长期下载链接及链接失效时间。界面说明收起／隐藏／读取条件变化会清除预览；已交给浏览器或保存到磁盘的文件无法由系统撤回。原已下载文件不受后续权限变更控制。

## 4. 实施与验证边界

实现文件为`frontend/src/api/knowledgeMarkdown.ts`、`frontend/src/components/KnowledgeMarkdownExport.vue`及两个局部调用入口。既有版本GET与OpenAPI 7.68.0保持，不增加后端调用副作用；静态检查、完整类型检查、构建和独立复核结果记入[唯一开发记录](../开发记录/开发阶段与进度.md)。

本地不启动应用、浏览器预览或数据库，不编写单元测试。本契约以下场景全部**待服务器执行**；文件存在、类型／构建成功不代表下载、权限或视觉验收通过。

## 5. 服务器验收场景

| 编号 | 场景与预期 |
|---|---|
| KMD-01 | 知识详情展开导出：网络重新读取确切发布版；预览全文及身份与响应一致；没有自动下载 |
| KMD-02 | 编辑区有未保存输入，或草稿已保存但未发布：导出保持原发布版，原草稿与编辑状态不变 |
| KMD-03 | 历史选择旧版并打开另一版对照：只导出当前所选版本，不混入当前最新版或对照版 |
| KMD-04 | 超过100行正文且阅读定位到后页：完整文件包含所有原文；首尾空行、CRLF／LF及代码块保持 |
| KMD-05 | 标题包含引号、冒号、换行、额外YAML换行／控制字符及类似属性文本：仍只有固定元数据字段，不改变文件路径 |
| KMD-06 | 版本响应ID／版本号不匹配，或正文、标题、时间无效：显示错误，没有旧文件或可下载正文 |
| KMD-07 | 请求超时／401／403／404后主动重试：重新读取同一确切版本；错误期间不使用旧缓存导出 |
| KMD-08 | 请求途中切对象、版本、退出重登或组件卸载：迟到响应丢弃，不展示、不自动下载 |
| KMD-09 | 预览中切换训练资料条件、检查权限、出现挑战或训练命令锁定：立即清除；恢复后须重新展开读取 |
| KMD-10 | 父级v-show、隐藏／inert／aria-hidden／visibility、浏览器页签隐藏或KeepAlive停用：清除并关闭；恢复时无旧可下载文件 |
| KMD-11 | 预览后立即变化登录／训练访问epoch再点下载：拒绝旧文件，要求重新读取；不发起过期下载 |
| KMD-12 | 点击下载及浏览器限制下载两种情况：仅发起用户请求、错误可重试，状态不声称已落盘；临时对象URL被回收 |
| KMD-13 | 正文含站内知识链接、Wiki语法、HTML、插件文本、附件或远程图片：原文保留；预览与导出不执行、不抓取其他内容 |
| KMD-14 | 已归档知识的可读历史：允许按现有GET权限导出原版，不恢复知识、关联、审阅或复习状态 |
| KMD-15 | 只用键盘展开、阅读原文、重取、下载、收起，及窄屏长标题：焦点可见、状态可感知、内容不撑破容器 |
| KMD-16 | 核对遗漏说明、元数据、浏览器生成时间、真实文件内容和下载状态；导出后来源变更不声称可撤回已下载副本 |
