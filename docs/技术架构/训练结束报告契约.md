# 训练结束报告契约

日期／版本：2026-11-08 · v1.0。状态：S6 第三批静态检查与前后端构建通过，待服务器验收；证据见[开发记录](../开发记录/开发阶段与进度.md)。对应 [PRD](../需求文档/产品需求文档.md) REV-07、TRN-03，复用[训练会话](训练会话与作答接口与数据契约.md)及[自检反馈](自检反馈与改进动作契约.md)。

## 1. 报告范围

- 仅汇总本人 ENDED 训练。记录实际结束时间、模式、配置、固定背景身份、题目状态、既往曝光与整场计时；不把整场观察时间当作单题净作答时间。
- 提交题数与提交次数以不可变 `training_answer` 为准；最后题目状态、已保存草稿与提交事实分开展示。有提交后再跳过仍计入已提交题数，草稿和未答结束不虚构提交。
- 结束事实固定，人工反馈、动作来源和 AI 任务状态是查询时的动态汇总，明确 `asOf`。无需等待全场 AI 成功，任意一题的结果可单独阅读；局部请求失败不隐藏已读取部分。
- 每题按提交修订倒序分页，包含全部真实提交而非只有最新答案。每次提交提供确切 `sessionId/questionId/answerId` 复盘入口，沿用既有逐答案访问确认。
- 报告是只读目录，不包含回答正文、图正文、个人参考、反馈观察、原文引文或背景正文，不自动授权访问或触发模型。

## 2. 状态与统计口径

- AI 任务保留八种原始状态及任务入口：QUEUED、RUNNING、VALIDATING、SUCCEEDED、FAILED、UNKNOWN、CANCEL_REQUESTED、CANCELED。没有任务为“尚未生成 AI 评价”；失败、结果未知、取消分别说明，不合并为能力不足。
- 成功只表示任务流程完成。无标准、观察不确定、缺少证据或用户争议都不能推导为执行失败、能力缺陷或总分。重试／未知费用核对使用原任务详情，不新增整场自动生成或批量重试。
- 人工反馈按当前反馈修订的 SELF_CHECK／EXTERNAL_FEEDBACK 类型计条目数，不把历史修订重复计数；人工反馈存在不等于用户已接受。
- 动作按稳定来源 ID 统计全部来源和其中 TRACKING 数，合并不重复计数，停止跟踪不等于完成。完整逐来源结果由复练入口读取。
- 已确认评价访问的布尔值只说明这次提交的访问记录；页面仍服从当前全局训练资料守卫，不能凭旧布尔值绕过正在进行的独立训练。

## 3. API 与类型

新增只读接口使用现表聚合，不新增迁移、任务、外发、配置或依赖。以 `TrainingReportDtos` 与 S6 OpenAPI 为准。

| 路径（GET，前缀 `/api/v1/review`） | 内容 |
|---|---|
| `/sessions/{sessionId}/report` | Report：结束事实、统计、背景身份、全部题目目录、查询时间 |
| `/sessions/{sessionId}/questions/{questionId}/report?before=&limit=` | SubmissionPage：确切题目、查询时间、提交目录与后续游标；before 1–101，limit 1–20，默认 10 |

所有 ID 必须为标准小写 UUID。非 ENDED 返回 409 `REVIEW_REPORT_NOT_ENDED`，不存在／跨 owner 返回 404 `REVIEW_NOT_FOUND`，非法参数返回 400 `INVALID_REQUEST`。读取使用 REPEATABLE_READ；所有路径及响应沿用 `/review` 资料守卫。一个请求内部的计数／列表保持同一读取快照；跨请求刷新可能看到新评价，页面展示各自查询时间。
