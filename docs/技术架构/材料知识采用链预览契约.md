# 材料知识采用链预览契约

版本：v1.0 · 2026-11-12。状态：静态检查通过待服务器验收，适用S8第二十四批，累计OpenAPI 7.53.0及生成类型已配套，后端打包、完整前端类型检查／构建及独立静态复核通过。本契约仅定义实际知识采用链的只读预览，不代表材料更正传播或完整生命周期已经完成。实际检查以[开发记录](../开发记录/开发阶段与进度.md)为准，下列服务器场景全部未执行。

## 1. 范围与证据

从本人确切材料摘录出发，核原始`ai_material_draft_source`、父任务及知识采用决定；只有`KNOWLEDGE_DRAFT + ADOPTED`且固定目标身份完整的记录形成第一跳。输入登记、成功任务、未决定或IGNORED均不表示正式采用。合法QUESTION_DRAFT登记不进入本知识链，也不表示没有题目影响。

后续只沿`ai_knowledge_source`及真实知识采用决定展开。源知识的实际选用版本须不早于上一跳目标的采用版；后续人工发布版本保守纳入影响候选范围，但不证明后续全部正文来自原材料。每条边保存实际选用源版和实际采用目标版，不能把“采用版及后续版本范围”伪装成同一版直接复制关系。

循环及菱形按真实采用边去重，保留一条可核对的最短发现路径。不同版本下限不能被同一对象的首次访问永久截断。图中节点包含目标采用版和实际使用的后续源版；当前／历史只比较今天的真实发布指针，不作为内容正确、用途允许或已复核的结论。

全部可达知识版另交给既有[材料用途祖先核对](知识材料用途祖先契约.md)，一次核对原实际采用、固定清单摘要及原始来源绑定。缺少历史见证、损坏数据或超限不能被静默跳过或显示为空图。只读预览不以今日ACTIVE／ALLOWED过滤历史，不重新授权或调用模型；既有祖先解析仍可能读取内部固定正文以校验证据，但响应不携带这些正文。

## 2. 接口与数据

`GET /api/v1/materials/excerpts/{id}/knowledge-adoptions`。不接受任何查询参数或分页参数；沿原登录、本人数据、资料模块启用和独立训练资料访问守卫，响应`Cache-Control: no-store`。单次REPEATABLE_READ只读事务，事务超时20秒；刷新重新读取，不是后续命令的冻结影响清单。

响应为封闭的五字段：

| 字段 | 规则 |
|---|---|
| coverage | 固定`REGISTERED_KNOWLEDGE_ADOPTIONS_ONLY` |
| source | 既有MaterialReferenceSource六字段，保留确切附件及手工／解析身份，不含原文、文件名或磁盘路径 |
| lifecycle | 既有MaterialLifecycleState八字段，与source的摘录、附件和创建时间一致；仅是此次读取的状态 |
| nodes | Node7数组，按versionId字典序；最多200个确切知识版本，versionId唯一 |
| edges | Edge9数组，按depth、id排序；最多500条真实采用边，id唯一 |

`Node7={itemId,versionId,versionNumber,kind,title,status,current}`，全部必填。kind为NOTE／CONCEPT，status为ACTIVE／ARCHIVED；versionNumber为正整数，title为该确切版标题，current为布尔值。

`Edge9={id,parentId,depth,domain,sourceItemId,sourceVersionId,taskId,targetItemId,targetVersionId}`，全部必填：

- domain为MATERIAL_EXCERPT／KNOWLEDGE。id为`domain~taskId~(sourceVersionId或excerptId)`，三部分均按原值组成；UUID使用标准小写格式。
- 材料第一跳：depth=1，parentId与sourceVersionId为null，sourceItemId等于根excerptId。
- 知识后续跳：parentId指向更浅一层的已返回边，depth=parent.depth+1；sourceItemId等于parent.targetItemId，实际sourceVersionId对应节点的版号不小于parent目标版号；目标和源节点的item/version须匹配。
- 不返回孤立节点；无实际知识采用时nodes与edges均为空。空图只说明此次登记的知识采用链没有边，不代表其他模块没有引用。

原始行从登记出发LEFT JOIN父任务、决定和版本，不能用INNER JOIN或状态过滤隐藏缺父对象／错绑定。每个知识对象的原始后代登记可缓存后按当前可达版号下限过滤；读取较早、不受当前下限影响的行也参加完整性检查及读取额度，不据此制造影响边。

反向预览上限为200知识版、500边及2500条原始登记行。按任务／源身份缓存和去重，超过任一上限返回`409 MATERIAL_KNOWLEDGE_PREVIEW_LIMIT`，不返回截断结果。随后一次正向祖先证明另受其既有200节点／500实际采用／2500绑定／200摘录预算约束；两种方向的预算独立，不宣称总查询量只等于反向上限。SQL超时、驱动或数据库故障沿原异常协议，不改报为普通空图。

参数错误沿`INVALID_REQUEST`400，摘录不存在沿`MATERIAL_NOT_FOUND`404，资料关闭沿`MATERIALS_DISABLED`503。缺历史见证和祖先超限沿既有明确409；身份损坏沿500。客户端保留错误并允许主动重读，不显示“没有影响”。

## 3. 界面与权限

在真实材料详情的确切摘录中主动展开“实际知识采用链”，再读取本接口；收起、页面隐藏、会话或训练资料条件变化时清除可见结果并拒绝迟到响应。恢复查看条件后由用户主动重新读取。原材料编辑和未决命令的导航守卫保持。

展示每条采用的原任务、确切知识版、当前／历史标记、深度与上级路径；明确后续人工版是保守范围。分别提供知识确切版及原任务入口，通过既有路由和资料守卫；只打开入口，不自动采用、复核、展开正文或调用模型。需要核对其他出口时，回到知识详情使用既有直接引用目录。

前端重新校验封闭字段、标准ID、节点及边排序／唯一、根身份与生命周期一致、目标及源版本、父边和深度、采用版下限、无孤立节点及上限。返回损坏结果时显示核对失败，不展示部分链。

## 4. 保持的边界

本批不创建材料更正根、生命周期事件或持久影响，不写复核决定、不暂停卡片或重算成长、不改变材料许可。既有[材料生命周期](材料摘录生命周期契约.md)对已采用内容及不支持绑定的四动作阻塞保持。生命周期事件只表示状态／用途变化，不是摘录正文被更正的证明。

题目、准备、事实、关系、审阅、训练固定内容、回忆及其他出口没有被本预览穷尽；本接口不声称已检测它们的全部阻塞前沿。一般主题／结构关联不能自动当作内容派生。预览与后续命令可能处于不同快照，真正放行材料动作仍须在owner命令事务内重新核完整支持范围，并接通用途代次、内容复核、历史冻结与相关下游守卫。

## 5. 服务器验收场景

以下全部未执行，静态检查与构建不能替代运行验收。

| 编号 | 场景 |
|---|---|
| MKP-01 | 根摘录、附件READY／SHA关联、生命周期基线与创建时间一致；跨owner、缺失或损坏根拒绝 |
| MKP-02 | 未发送、失败、成功未采用和IGNORED不建知识边；合法题目登记不混入知识链，真实ADOPTED显示确切目标 |
| MKP-03 | 缺父任务、错用途、未知任务／决定状态、目标缺版／错归属故障关闭，不因联查过滤而输出空图 |
| MKP-04 | 多个材料任务采用同一知识不同版，均保留真实边；已归档知识和历史采用版仍可按权限预览 |
| MKP-05 | 知识链只扩展采用版及其后续实际选用源版，早于采用版的输入不误入；后续手工版不被冒充为原材料直接生成 |
| MKP-06 | 循环／菱形、同对象不同下限及多源任务去重有界，父路径深度正确，版本及任务不串绑 |
| MKP-07 | 根及后代全部原始登记参与额度；200节点／500边／2500行边界超限409，无部分图；祖先证明原预算独立保持 |
| MKP-08 | 固定Manifest／hash／原绑定完整性核验；缺历史见证明确409，不能用今天版本补过去 |
| MKP-09 | 响应封闭、排序稳定，无孤立节点，source与lifecycle同根同附件；不返回正文、清单、引文、文件名或路径 |
| MKP-10 | GET拒绝全部查询、登录及资料／训练守卫覆盖、no-store；读取未写事件、影响、许可或排程 |
| MKP-11 | 主动展开／刷新、收起与隐藏清屏、会话或权限变化、慢请求迟到拒绝、错误重读和空图范围说明 |
| MKP-12 | 原任务及知识确切版导航经过草稿守卫，不自动采用、授权或复核；知识目录继续核其他出口 |
| MKP-13 | 预览后另标签新增采用或更正，刷新使用新快照；预览不构成生命周期放行，既有四动作仍按原守卫拒绝 |
| MKP-14 | MyBatis真实映射、REPEATABLE_READ、查询计划、长链／扇出耗时和内存、键盘／窄屏／服务器视觉验收 |
