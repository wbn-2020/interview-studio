# 材料摘录生命周期契约

版本：v1.2 · 2026-11-12。状态：代码完成待验证；本批后端打包、完整前端类型检查／生产构建及机器契约静态检查通过，831项构建输入前后无漂移；独立复核及最终证据见开发记录，第十三批原证据保留。适用S8第十三／十四批；沿用V73，本批不新增迁移，累计OpenAPI 7.43.0，前后端配套。进度与实际证据以[开发记录](../开发记录/开发阶段与进度.md)为准。23项服务器场景均未执行。

## 1. 业务边界

确切摘录新增独立状态 `ACTIVE/ARCHIVED`、AI 用途 `ALLOWED/REVOKED` 及单调安全整数 `revision`。归档阻止新的本地选用及 AI 使用；撤回 AI 用途仍允许本地读取与依据保存，但禁止直接或经准备事实／表达再次外发。恢复不改变 AI 用途，重新允许不改变归档状态。四个动作分别为 `ARCHIVE/RESTORE/REVOKE_AI/ALLOW_AI`，只接受实际状态转换，每次 revision 加一；回到相同状态也不能恢复旧授权。

第十四批允许**只有合法直接AI输入登记、尚无任何正式采用内容及其他本地绑定**的摘录变更。六入口包括知识整理、题目整理、资料问答、材料事实候选、材料关系候选、跨域来源问答；失败、取消、未发送、进行中或成功但未采用的任务本身不阻止四动作，合法IGNORED决定也不阻止。任务状态或输入登记不证明已外发、收费或采用。

准备任一历史版本、正式关系直接材料证据、标准审阅任一原始绑定仍原子拒绝；相关AI任务存在任一ADOPTED知识／题目／事实／关系决定也拒绝，关系补充同样属于采用。不因目标归档、改版、关系移除或审阅撤回解除限制。四动作全部遵守此边界，包含“重新允许AI”；撤回后建立本地准备依据，后续重新允许也可能被该绑定阻止。缺父任务、错用途或异常绑定故障关闭。用户可先查看[直接引用预览](材料摘录直接引用预览契约.md)，但展示查询不能代替命令守卫。

材料派生知识的内容复核与AI用途许可是两条不同规则，不能让KEEP_CURRENT默默恢复原材料外发许可。本批不开放已采用内容的材料变更，不新增其多跳传播或复核处理；这部分仍属后续完整范围。不删除原件、解析、摘录、关系、任务、费用或回执。

第十五至二十二批另接[知识材料用途祖先检查](知识材料用途祖先契约.md)，沿实际知识采用链汇总直接摘录、确切准备及表达最终事实直接材料，再保守继承原表达全部FACT来源、原事实全部材料，以及知识／FACT原训练采用的整张固定答案图引用。知识trainingDraft另核固定题面、确切题库版及原AI出题全部知识／准备／材料来源；显式选定评价时再核成功任务／尝试、原Manifest／hash、完整固定输入、本题确切参考及完整报告，逐任务核所选反馈。无题库FOLLOW_UP v2再核成功生成原绑定、完整候选／生成快照、确切父问／父答及原任务实际发送的背景，只有保存检查CURRENT子序列继承准备材料，不用今天状态补造。REPLAY核真实同题绑定及配置、基线原答身份与完整原题复制，沿确切原题继续继承；个人回忆只核确切历史版及题面投影，不误扩未复制的原答图、回忆反馈或面试安排。旧1／未知追问版的新祖先用途故障关闭，历史读取保持。报告或候选引文不缩小原输入材料路径，未保存的整份报告摘要不补造。新AI清单保存独立许可代次，FACT TRAINING不增加题面或评价依赖。表达删去最终依据、事实后续移除材料、题库手工后续改版或训练只选部分文字均不缩小原来源；旧显式数组遗漏扩展材料须新预览，历史摘要／回执保持。该前置不代替全部派生出口，不改变本文第十四批四动作阻塞边界；事实历史父项目、未明确选定的评价或参考、隐式训练背景、白板原文等其他路径及完整材料更正传播仍待闭合。累计规格及各批实际检查见开发记录，本文第十四批检查结论不覆盖后续源码。

第二十三批为上述原FACT检查中明确保存的父项目代次补充确切项目版见证：相同单调代次核真实current指针，已变代次只用V71真实事件端点，不按今日版或时间猜历史。该项目版的材料属于用途资格依赖，不证明原事实复制了项目正文。缺见证阻止新预览／重建，普通历史读取的当前资格为false；不吞数据库、损坏或额度错误。没有捕获代次的其他FACT路径、真实材料更正根／完整传播及已采用材料四动作仍保留后续边界，本文第十四批原检查不替代本批验证。

第二十四批另提供[材料实际知识采用链预览](材料知识采用链预览契约.md)：从原始材料登记核真实知识采用，再沿知识采用版及后续实际选用版本保守展开，返回确切版本、原任务及多跳路径。它只读、不创建材料事件或持久影响、不更改许可和本文命令守卫；题目等其他出口仍未穷尽，不能凭预览放开已引用材料四动作。实现与实际检查见唯一开发记录。

第二十五批的[知识链AI用途变更](材料知识链AI用途变更契约.md)仅补充动作准入：`REVOKE_AI／ALLOW_AI`可支持在owner命令事务内完整重建、核验历史且无未支持原始出口的真实知识采用链；`ARCHIVE／RESTORE`继续按本文原采用阻塞。直接其他采用及题目、卡片等知识出口仍保守拒绝。沿用原revision、V73事件及接口，许可变化不是正文更正，不新增内容待复核或暂停本地复习；重新允许不复活旧清单／授权。本文第十三／十四批检查仅对应历史快照，本批状态与证据见唯一开发记录。

第二十六批另接[固定摘录更正声明](固定材料摘录更正契约.md)：本人旧摘录到另一条新固定摘录的内容更正事实，不推进V73修订或更改两端正文／用途。仅无正式采用及其他本地绑定的原范围可声明；旧端此后退出新选用和AI当前资格，四类生命周期命令也不能覆盖更正事实。ACTIVE选择列表与新搜索排除旧端，ALL及确切历史、原事件及旧回执保留。此处的ACTIVE／ALLOWED及hasReferences不单独证明仍可新选用；内容影响及已采用材料更正仍待后续，实际检查见唯一开发记录。

## 2. 持久化与并发

V73 新增生命周期及追加式事件表，为现存摘录保存 ACTIVE／ALLOWED／revision=0 基线，不补造历史事件；新摘录与基线在原创建事务中保存。缺失基线是完整性错误，读取不补写。保留原摘录正文和 `MaterialAiExcerpt` 11 字段。

命令复用 `IdempotencyService` 的 owner 写锁、事务及原键回执。状态读取的hasReferences仍对八表按owner／excerpt执行原始EXISTS：`preparation_material_reference`、`ai_material_draft_source`、`ai_material_qa_source`、`ai_fact_draft_material`、`ai_relation_evidence_material`、`ai_source_qa_source`、`knowledge_relation_evidence_material`、`standard_review_evidence`。不以任务成功、当前修订或是否采用过滤，语义及State8格式不变。

命令锁内先核expectedRevision和有效转换，再用独立hasUnsupportedReferences判定本批阻塞：

| 原始绑定 | 阻塞条件 |
|---|---|
| 准备、正式关系材料证据、标准审阅 | owner／excerpt任一原始行即阻塞，不联查当前父对象或修订 |
| AI材料整理 | 任务必须是KNOWLEDGE_DRAFT／QUESTION_DRAFT |
| AI资料问答 | 任务必须是MATERIAL_QA |
| AI材料事实 | 任务必须是FACT_DRAFT；材料行及专用来源父行均为MATERIAL |
| AI材料关系 | 任务必须是RELATION_DRAFT；材料行及专用来源父行均为MATERIAL |
| 跨域来源问答 | 任务必须是SOURCE_QA；摘录行domain为MATERIAL_EXCERPT |

每个原始AI登记任务再核四类决定表；任一ADOPTED或未知决定状态阻塞，只有无决定或合法IGNORED可继续。原始AI行先匹配，再核父任务／专用来源；缺失、用途不符或不支持身份不能因INNER JOIN被漏掉。关系采用不筛supplement_id，也不联查正式边是否仍存在。所有新建绑定、采用及生命周期继续共用owner锁：采用先提交则动作拒绝；动作先提交则原任务材料代次失配、采用拒绝。状态、追加事件与回执同事务，失败不保存半个动作。成功State8按八表重新求hasReferences，可为true。

## 3. 接口

全部接口保留登录、owner、资料启用和原训练资料访问守卫，响应 no-store；标准小写 UUID、严格请求字段和类型。状态读取及分页为只读事务。

| 方法与路径 | 请求／响应 |
|---|---|
| `GET /api/v1/materials/excerpts/{id}/lifecycle` | State8 |
| `POST /api/v1/materials/excerpts/{id}/lifecycle/changes` | Idempotency-Key；Change4 → State8，200 |
| `GET /api/v1/materials/excerpts/{id}/lifecycle/history?after=&limit=20` | HistoryPage3 |

- `State8={excerptId,attachmentId,status,aiUse,revision,createdAt,updatedAt,hasReferences}`，全部必填。hasReferences只是已登记引用的保守检查，不是命令可执行性判断，也不是完整删除清单。
- `Change4={expectedRevision,action,reason,confirmed}`，全部必填；expectedRevision 为 0–9007199254740991 整数，confirmed 必须 true，reason 去首尾空白后为 1–1000 个 UTF-16 单元，拒绝 NUL／不成对代理字符。
- `Event11={id,excerptId,action,previousStatus,previousAiUse,previousRevision,status,aiUse,revision,reason,createdAt}`，全部必填。按 revision 递增；事件不含摘录正文。
- `HistoryPage3={excerptId,items,nextCursor}`；limit 1–20，默认20；游标 `excerptId~revision` 最多60字符，revision 为正安全整数。拒绝未知、重复、空或非法查询；limit+1 分页，nextCursor 等于满页末项身份。读取不是跨请求冻结快照。
- 参数错误沿 `INVALID_REQUEST` 400，根不存在沿 `MATERIAL_NOT_FOUND` 404；新增409：`MATERIAL_REVISION_CONFLICT`、`MATERIAL_STATE_CONFLICT`、`MATERIAL_HAS_REFERENCES`、`MATERIAL_NOT_ACTIVE`、`MATERIAL_AI_USE_REVOKED`。模块关闭沿 `MATERIALS_DISABLED` 503。基线／数据完整性错误不伪装成空页或无引用。

附件摘录列表新增可选 `status=ACTIVE/ARCHIVED/ALL`（默认ACTIVE）、`aiUse=ALLOWED/REVOKED/ALL`（默认ALL）；原 cursor／q／limit 保留，limit仍为1–50，q允许空字符串。参数白名单与重复检查一并严格化，枚举、cursor和limit不接受显式空值。统一搜索默认排除归档摘录；显式原摘录、原版本及历史读取保留。本地选取器只选 ACTIVE，AI 选取器额外筛 ALLOWED。

请求JSON最多20000字节、单字符串读取上限10000；理由按Java `String.strip()`的空白集合去首尾，再核1–1000个UTF-16单元，保留NBSP、U+2007、U+202F及BOM，前端与机器规格使用相同集合。事件保存规范化理由，历史读取不改写原文。直接材料捕获可返回`MATERIAL_AI_USE_REVOKED`，间接准备来源沿既有AI来源不可用／变更协议拒绝；不把间接失败强行换成新材料错误码。

## 4. AI 清单与间接用途守卫

Manifest 新增可空且 NON_NULL 的**尾字段** `materialChecks`，元素封闭为 `{excerptId,revision}`。新含材料清单必须保存全部不同的直接材料 ID，按 ID 字典序排序，完整核重复／缺失／多余、状态／用途／代次。覆盖知识整理、题目整理、资料问答、材料事实候选、材料关系候选、跨域来源问答六种入口。SOURCE_QA 的同摘录多个片段只保存一份 check；其内部固定 Source／Check／MaterialContext 不变。

新 checks 同时参与 Manifest hash 与持续授权 scope hash；空尾只沿原兼容省略规则处理，不全局清 null，不重写历史 JSON／hash／回执。旧清单没有 checks 时，只允许其全部直接材料仍 ACTIVE／ALLOWED 且 revision=0；无材料模式不得混入非空 checks。新建任务由服务器重建清单并比摘要，客户端不能省略 checks 绕过。

归档或撤回发生后再建立的本地准备依据不能绕过：TARGET／PROJECT／FACT 的确切版本登记材料必须允许 AI；FACT 同时核父项目当前版本的登记材料；EXPRESSION 核原保存的全部 FACT_BASIS 确切事实及其父项目材料。资格查询只读材料元数据，不扩大外发正文。准备读取、新预览、SOURCE_QA 的准备来源和统一任务当前性路径接同一资格规则。训练追问实际外发的固定准备背景也核相同资格，保持原快照正文；评价／改写／比较没有外发准备背景时不扩大限制。此限制不禁止本地事实／表达或训练背景保存，不把 AI 用途混入普通本地历史状态。

提交、重试、排队领取、发送许可、结果接纳、候选采用、持续授权及暂态正文复用统一当前性守卫。第十四批允许上述未采用AI登记变更后，原任务materialChecks失配；旧null尾也因revision已不为0而失效。旧成功结果仍可按原访问规则读历史，当前资格单独返回false，不抹掉正文。新预览使用新revision，完整清单和持续范围授权scope随之改变；旧授权条目可能仍显示ACTIVE，但不能授权新代次，也不能基于失效旧任务授予新范围许可。

撤回提交后，后续资格核对拒绝旧任务的发送许可、暂态读取、结果接纳、采用与重试。任务不会因此被同步改为CANCELED；RUNNING的有效租约仍按原状态机处理。已获得发送许可的事务外请求可能继续到达供应商，已经发出的正文或浏览器已收到的片段不可收回；最后一次流式核对与网络写入之间也存在窗口，不能承诺撤回后零新增字节。结果接纳先保留实际或未知费用，再拒绝发布失效候选；只对可证明未发送的请求释放预留。不新增供应商实时取消、不改历史JSON／hash／费用／回执，不宣称间接派生更正已完成。

## 5. 界面与原请求恢复

在材料详情的确切摘录内主动展开生命周期面板，读取状态／引用存在性和分页历史；历史只读组件不自动出现命令中心。四个动作独立，填写理由并确认后提交。hasReferences=true仅提示已登记引用及本批边界，不提前禁用所有动作，也不代表已经可执行；由服务器锁内核对不支持绑定，必要时MATERIAL_HAS_REFERENCES拒绝。显示直接引用入口、在途发送／费用限制；冲突重新读取当前状态，不自动代用户重新确认。

复用既有 useCommand 和会话／资料访问守卫；断网保留原请求及幂等键，未决时禁止更换摘录／动作覆盖请求。隐藏、会话／权限／来源变化清空可见资料并拒绝迟到响应，不能丢未决命令。结果回执与当前状态分别展示，旧回执不冒充当前状态。
