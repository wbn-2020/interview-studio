# 训练背景更正与 AI 使用契约

日期／版本：2026-11-07 · v1.0。适用 S5 第七批，状态：静态检查与前后端构建通过，待服务器验收。关联 [PRD](../需求文档/产品需求文档.md) MAT-05、AI-02／04、[准备契约](准备与资料接口与数据契约.md)、[训练契约](训练会话与作答接口与数据契约.md)及 [追问契约](训练AI追问契约.md)。进度及检查证据仅维护在[开发记录](../开发记录/开发阶段与进度.md)。

## 1. 历史与当前使用

- 训练保存的 TARGET／PROJECT／FACT 背景、题目和原答保持当时的确切版本。更正、核实撤回、归档不替换历史正文，不禁止手工继续作答、保存、暂停或结束。
- 训练详情额外读取每项固定背景的当前可用性。它表示“现在是否可用于新追问”，不表示该旧版本当时的核实决定，也不把重新确认等同于模型用途授权。
- 新追问只默认纳入仍为当前活跃版本的目标／项目；事实还须当前 CONFIRMED 且所属项目 ACTIVE。失效背景从本次模型输入排除，预览逐项显示排除状态；不会用最新正文替换旧快照。全部背景失效时仍可基于题干与确切提交生成追问。
- 原答、题干及图中文字可能由用户自行写入相同事实，系统不猜测或删改这些文字。完整发送预览必须明确此边界；用户可以取消本次生成，或先提交更正后的新答再选择它。
- 已加入的追问保留。背景变化在训练中提示待复核，不删除旧题、不倒改答案条件、不将原报告认证为正确。答案评价目前不附加背景，本批不因背景变化阻断对原答的评价。

## 2. 状态与代次

当前状态为 `CURRENT|SUPERSEDED|WITHDRAWN|ARCHIVED|PROJECT_ARCHIVED|UNVERIFIED|UNAVAILABLE`。核对 owner、类型、对象及确切版本；不可访问或错配返回 UNAVAILABLE，不返回其他对象标题或正文。状态按不可用、当前事实撤回、对象归档、所属项目不可用／归档、事实未确认、版本更替、CURRENT 判定。当前版本状态不能冒充历史版本核实记录。

V18 为 `preparation_item` 增加 `source_generation`，默认 0。保存正文、归档／恢复、确认／撤回与实体 revision 同事务递增；收藏、关注目标不改变此代次。范围为 0 至实体 revision，受既有 JS 安全整数上限保护。事实检查同时固定自身与所属项目代次。

代次用于识别撤回再确认、归档再恢复等往返变化；即使正文和当前状态恢复相同，之前的任务授权仍失效。用户可重新预览并新建任务。迁移前历史不推测代次，旧未决追问清单缺少检查记录时拒绝新发送／接纳，原历史结果与费用恢复保留。

## 3. 读接口与清单

`TrainingContextCheck={kind,itemId,versionId,title,number,state,sourceGeneration,projectGeneration}`：身份、标题与版本号取训练固定快照，state 和两项可空代次取当前受权读取。最多 12 项，顺序与背景相同；非 FACT 的 projectGeneration=null。缺失对象的代次可空，不能按 0 或 CURRENT 补齐。

- `TrainingSession` 追加可空 `contextChecks`：常规详情及新命令回执返回数组，旧幂等回执缺字段时保持 null，界面显示尚未核对并读取当前详情。
- `AiManifest` 追加可空 `contextChecks`：新 FOLLOW_UP 为全部背景的检查数组（无背景为 `[]`），其他用途为 null；参与授权摘要。旧清单 null 表示缺少核对，不伪造当时状态。
- `AiManifest.training.context` 只含 CURRENT 背景的原有白名单正文。`contextChecks` 是本地权限／失效依据，不发给模型；被排除的标识、标题、状态、代次也不通过该字段外发。模型网关继续只序列化明确的 training 输入。
- 追问 promptVersion 升为 `training-follow-up-2`。新预览、创建、重试、发送前和接纳前共同核对清单与当前检查数组；排除集合变化同样需要重新授权。读取历史清单不触发任何发送。

## 4. 事务、恢复与界面

来源读取与训练／任务读取在同一快照事务中完成；创建、任务领取、发送边界、接纳及准备变更沿用同一 owner 写锁串行核对。不在数据库锁内等待模型响应。最后检查后仍可能发生撤回，不能声称可以收回已发送请求；返回时再次核对，失效结果不追加追问，已发生或未知费用按原规则保存。

源状态改变使任务不再 eligible，界面要求重新预览并创建；不自动换内容、换幂等键或复活旧任务。未发送失败释放预留；已经可能发送的失败保留实际／未知费用；取消、核对账单及原键回执恢复仍可用。确认后再次发生变化也不能复用旧授权。

训练显示原版本与当前状态；旧回执无法提供检查时提示重读。追问预览分清实际发送背景与本地排除说明，核对状态改变时废弃先前预览／同意，不覆盖答案、决定原因或费用输入。独立训练只能读取已固定的背景及状态，不借此读入新版本正文、附件或关联知识。

本批收口 AUD-04 中核实撤回／更正／归档对新追问的默认使用和在途接纳。持续用途授权及撤权、旧版事实单独撤回、全量反向影响列表与间接派生传播仍依 S5 后续和 S8，不将本批视为完整生命周期已完成。
