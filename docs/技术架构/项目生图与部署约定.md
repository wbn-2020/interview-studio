## 文字 AI 入口

2026-11-20 用户指定 Maxdle 的 Responses 接口，并确认免费／包月按零边际费用配置。本项目文字模型使用 `gpt-6.1-sol`，完整端点为 `https://maxdle.com/v1/responses`。本地私有配置在 Git 忽略的 `.env.ai`，线上通过应用环境变量 `STUDIO_AI_*` 注入；密钥仅在后端使用，不进入前端、公开文档或提交。生图仍使用下节独立配置。

当前配置采用 `RESPONSES`、4096 输出 token 上限、120 秒超时，输入／输出单价为零，价格版本为 `subscription-zero-marginal-20261120`。日预算正数用于满足现有配置契约，零单价不会扣减该额度；它不表示供应商实际余额、账单或用量上限。以后改为按量付费时，必须同步真实单价、币种、日预算与配置／价格版本。

调整文字 AI 环境时，先独立备份现用应用配置并核对无关变量不变，再重建应用容器使环境生效；核对代理、登录、AI 配置与一条真实任务。失败时恢复原配置并重建应用。配置就绪不等于每个 AI 用途均已验收；实际覆盖见[模型接入验收](../审查/常规回忆与文字AI验收-20261120-r158.md)与[评价追问验收](../审查/AI评价追问与训练导航验收-20261120-r159.md)。

## 生图入口

后续本项目生图使用[huantu images/generations](https://huantu.xyz/api/v1/images/generations)。根目录`.env.imagegen`包含`IMAGEGEN_PROVIDER`、`IMAGEGEN_GENERATIONS_URL`及`IMAGEGEN_API_KEY`；它被Git忽略，仅由本项目生图脚本读取。真实密钥不进入文档、请求正文、前端`VITE_*`变量或提交。

执行入口为[project-imagegen.py](../../.cache/scripts/active/project-imagegen.py)，使用已安装的Python标准库：

- `--check`只读取并检查指定配置，输出提供方、端点及配置状态。
- 实际生成同时传入`--request`与`--response`。请求为项目内JSON，明确包含提供方支持的`model`和图片描述`prompt`；其余参数按实际提供方能力填写。
- 响应保存到`artifacts/images/`内的新JSON文件，保留原始响应供后续确认和提取图片。响应不打印到会话。
- 凭据仅通过Bearer请求头发送到指定接口；不跟随重定向，不自动重试计费请求。

[配置检查记录](../../.cache/verification/results/project-imagegen-config-20261119.json)及2026-11-20复查均为`keyConfigured=true`、Git忽略且未跟踪、`apiCalled=false`。配置读取与脚本语法已检查；模型兼容性、实际响应及图片生成尚未验证，首次真实生成时按接口结果记录。
