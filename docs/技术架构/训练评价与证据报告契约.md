# 训练评价与证据报告契约

日期／版本：2026-11-23 · v1.2。适用 S5 第五批、第二十批访问复用及本批追问上下文说明。状态：本批上下文提示、追问评价预览及真实报告已完成[服务器验收](../审查/复审修复与服务器验收-20261123-r163.md)；其余场景的实际覆盖见[开发记录](../开发记录/开发阶段与进度.md)。关联 [PRD](../需求文档/产品需求文档.md) REV-01–04、REV-07、TRN-01／06／08、AI-02–06 与 [AI 任务契约](AI任务与外发契约.md)。本契约纳入单答证据报告与最小逐项决定；完整复盘、动作、复练比较仍按 S6 相关契约维护。

## 1. 业务与显示边界

- 用户明确选择一条不可变 `answerId`。评价只分析该次提交，不替换为最新答案，不读取未提交草稿。成功任务保存不可变报告；重新评价是新任务、新报告，旧报告保留。
- 评价前须按确切答案确认打开评价区。`AFTER_ANSWER` 在已提交后允许；`AFTER_SESSION` 在结束前须另勾选提前反馈确认。专项／模拟尚未结束且未允许辅助时，此操作原子记录 MATERIAL_ACCESS 并使之后提交为 ASSISTED。已有原答条件不倒改。
- 访问确认与外发授权分开。前者允许查看该答案的参考预览／报告；后者才允许第三方发送。确认记录一经保存不撤销，重复同答案不重复曝光；不会自动产生付费请求。
- 访问确认单独存储，不依赖结束后封闭的训练事件容量。对有题库来源的主问或追问根主问，追加 `EVALUATION_ACCESS` 曝光，含义是请求打开评价区，不证明用户实际阅读；之后新训练展示该计数。
- 通用 AI 详情、训练入口、命令重放均受资料守卫；另一场独立训练存在时不能查看旧场报告。仅任务状态／覆盖摘要不含参考、评价正文。已见内容不能撤回。
- 报告固定 `AI_UNREVIEWED`。当前题库仅支持个人未审标准；模型不能给自己授予“已审”身份，不输出总分、技术判错状态或岗位胜任结论。用户接受只是一项用户决定。

第二十批[改写参考](训练改写参考与并排展示契约.md)在同一已确认区域提供主动生成入口；现有访问确认允许打开该确切提交的参考与改写区，第三方外发仍需逐次授权。旧 `EVALUATION_ACCESS` 继续只表示请求打开评价区，不能改称实际阅读某份改写。改写使用独立表、任务额度、摘要列表和候选，既有评价配额、覆盖与用户决定不混入改写；原答条件保持原样。

## 2. 外发输入与引用

完整清单 `Manifest.evaluation` 包括：sessionId、questionId、answerId、答案修订号、模式、反馈时机、提交时辅助条件；当时固定题干的 title/prompt/conditions/technology/scenario/type；提交文字及图节点 id/label/description、边 id/source/target/label；确切题库版本的个人参考及检查点。AI 追问实例没有标准，standard=null。

本批不附加训练背景 TARGET／PROJECT／FACT、附件、知识正文、来源地址、图坐标或节点外链；因此不能据此判定项目事实真伪。后续扩充来源须先明确更正、核实撤回与用途撤回规则并重新预览授权。已提交答案中的个人文字仍在清单中，需用户自行核对。

2026-11-23补充：追问评价界面明确提示未附带父题和父答案。生成观察时，题干若依赖这些缺失上下文，须说明局限并使用 UNCERTAIN，不得据此认定用户答案未提及。新任务使用 `promptVersion="training-evaluation-2"`，历史任务保留原版本。该提示不扩展外发清单，模型执行质量仍需逐份核对。

前后端限制沿用 32 KiB 输入与既有费用预留；超限明确拒绝，不截断。评价在暂停或结束后仍可执行；其不可变输入不包含会话 generation，暂停／恢复／结束不使合法报告失效。取消、租约、运行授权代次、配置、未知终态与费用规则复用任务底座。

每项观察包含 dimension、coverage、observation、condition、basis、limitation、suggestion、citations。coverage 仅 MENTIONED／NOT_MENTIONED／UNCERTAIN。这些是模型观察，不认证正确、缺陷或能力。反馈 ID 由服务端按报告顺序分配 `f1`…`f12`，模型不得生成 ID。

引用绑定本报告的确切输入，包含 kind、elementId、start、end、quote。start/end 为字段原文 UTF-16 左闭右开区间，拒绝代理对中间边界；quote 必须逐字一致。普通文本引用 elementId=null；图节点／边和检查点须指定输入内存在的 ID。

| kind | 定位字段 |
|---|---|
| ANSWER_TEXT | answer.text |
| ANSWER_NODE_LABEL／ANSWER_NODE_DESCRIPTION | answer.nodes 指定元素的 label／description |
| ANSWER_EDGE_LABEL | answer.edges 指定元素的 label |
| QUESTION_PROMPT／QUESTION_CONDITIONS | question.prompt／conditions |
| REFERENCE | standard.referenceAnswer |
| CHECKPOINT | standard.checkpoints 指定检查点的 text |

MENTIONED 至少含一处答案证据。NOT_MENTIONED 不得带答案引用，至少含一处题干／条件／标准引用，表达“本次所查范围可能未提及”；零长度引用不能证明缺失。UNCERTAIN 可无引用，必须说明局限。所有引用只证明定位合法，不能证明语义或技术判断正确。

输出限制按 Unicode 码点：summary／limitations 各 1–2000；observations 1–12；observation 1–2000、condition 0–1000、basis／limitation／suggestion 各 1–1000；每项 0–6 个不重复引用，quote 1–500；文字总量最多 24000。模型输出严格字段、类型和枚举，无额外字段；level／validationNote／反馈 ID 由服务端添加。

## 3. 存储与一致性

- `ai_evaluation_access`：owner＋session＋question＋answer 唯一，保存是否提前查看与时间；访问和辅助事件同 owner 锁事务。
- `ai_evaluation`：task 绑定 owner＋session＋question＋answer，FK 防止跨对象错配。单答案最多 3 个评价任务，同时最多 1 个未决任务；失败重试沿用每任务最多 3 次尝试。成功旧报告不被新任务覆盖。
- 报告存既有任务 candidate_json；成功后不可修改。每条 `ai_feedback_decision` 追加 revision；第一条 expectedRevision=0，最多 20 次决定，保留完整改判历史。reason 为 0–1000 码点，DISPUTED 必填。接受／争议／忽略不改报告、原答、标准或成长状态。
- 全部写命令 Idempotency-Key，回执与业务同事务；同键异请求拒绝，双标签 CAS 冲突保留输入。费用结算与报告接纳独立判断，失败／取消／迟到不把已发生费用回滚。
- 覆盖摘要逐题统计**最新提交**的任务数、已成功／未决／失败数，无答案显示未提交。旧答案报告留在任务历史；不冒充最新提交已经评价。汇总无需额外模型调用，也不形成总分。

## 4. 接口

以下训练路径前缀 `/api/v1/training/sessions/{sessionId}`。

| 方法／路径 | 请求 → 响应 |
|---|---|
| GET `/questions/{questionId}/evaluations/access?answerId=` | → EvaluationAccess，不返回参考 |
| POST `/questions/{questionId}/evaluations/access` | EvaluationAccessRequest → EvaluationAccess；幂等，确认辅助与提前反馈 |
| POST `/questions/{questionId}/evaluations/preview` | EvaluationPreviewRequest → Preview；仅已确认访问，无付费调用 |
| POST `/questions/{questionId}/evaluations` | CreateEvaluation → Task（201）；已预览摘要与本次外发授权 |
| GET `/evaluations` | cursor、limit、可选 questionId → EvaluationPage，仅状态摘要 |
| GET `/evaluations/coverage` | → EvaluationSessionCoverage，最新提交范围 |
| POST `/api/v1/ai/tasks/{id}/feedback/{feedbackId}/decisions` | DecideFeedback → Task；幂等及逐项决定 CAS |

任务详情、取消、重试和费用核对复用 `/api/v1/ai/tasks` 既有路径；通用创建／预览不接受 ANSWER_EVALUATION，必须从确切答案入口创建。Task 新增 evaluation、evaluationReport、evaluationDecisions；Manifest 新增 evaluation，旧回执缺失字段视为 null，不能新增 primitive 必填字段破坏旧回执。

专用错误：`AI_EVALUATION_NOT_FOUND` 404；`AI_EVALUATION_ACCESS_REQUIRED`、`AI_EARLY_FEEDBACK_CONFIRMATION_REQUIRED`、`AI_EVALUATION_LIMIT`、`FEEDBACK_REVISION_CONFLICT` 409；输入／范围超限与既有任务错误按通用契约。
