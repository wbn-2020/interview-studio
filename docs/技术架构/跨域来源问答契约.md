# 跨域来源问答契约

版本：v1.1 · 2026-11-13。原问答及S8第三十八批显式知识冻结资格静态检查通过待服务器验收，运行与视觉未验收。适用：显式选择八域确切原文后的SOURCE_QA问答；承接[完整产品需求](../需求文档/产品需求文档.md)AI-02／AI-05、[统一检索](跨模块统一检索契约.md)及扩展、[任务与外发](AI任务与外发契约.md)、[持续授权](AI持续范围授权与撤回契约.md)。进度与实际验证仅维护在[开发记录](../开发记录/开发阶段与进度.md)。以下为实施规则，不代表用户逐项确认或服务器能力已经通过验收。

## 1. 用户流程与范围

在统一搜索主动查询 → 打开确切来源 → 选择一个白名单字段的原文范围并加入本次问答 → 跨域继续选取 → 填写问题 → 主动预览全部外发内容、限定、供应商和费用 → 明确授权创建持久任务 → 到原任务中心读取带出处的AI未审回答。搜索命中不自动加入清单，不把结果摘要、整库、相邻知识、关联事实或历史问答自动外发。

选择篮子和创建器位于搜索页并保持组件实例；换域、翻页或只重填检索条件清搜索结果而不替换选择。普通离开仍经过未保存／未决命令守卫；同一搜索组件只改变检索条件不卸载问答创建器。新来源必须由用户明确加入，失效项不能自动剔除或替换最新版。成功创建后提供原任务详情入口，不因导航失败另建任务。

新用途仅依据所选片段答复。无匹配、无来源或依据不足不自动切换通用解释、不额外召回、不再次调用。原[资料摘录问答](资料摘录问答契约.md)的MATERIAL_QA／GENERAL与excerptId引用语义保持；新问答不生成采用决定，不记录训练、复练或回忆完成。

## 2. 固定身份与选区

请求只包含question和有序selections，不接收客户端标题、状态、决定、条件、quote或owner作为权威来源。Selection为source＋ranges；Range为field／start／end，UTF-16原字段左闭右开区间。服务器重新读取白名单原文，完整字段可用0至原长度表达，不用搜索摘要偏移充当正文范围。

| 域 | source固定身份 |
|---|---|
| KNOWLEDGE／PREPARATION／QUESTION／RECOLLECTION | domain、对象id、versionId；其他身份尾为空 |
| MATERIAL_EXCERPT／TRAINING_ANSWER | id=versionId，分别为摘录／正式提交；其他尾为空 |
| REVIEW_FEEDBACK | id=versionId=反馈id，revision为1–100；AI尾为空 |
| AI_FEEDBACK | id=评价任务、versionId=成功尝试，feedbackId为f1…f12，reportHash为原报告字节SHA-256；revision为空 |

最多1–5个不同固定来源、合计1–8段，每段1–8000个UTF-16码元；同源同字段区间不能重叠，不切开代理对、不trim或规范化原文。sourceKey按来源顺序固定为s1…sN。question去首尾Java空白后1–2000个UTF-16码元。新外发问题、选区及所有必要限定不接受NUL或孤立代理；合法历史AI报告的NUL不被改判损坏，此时明确本次来源不适合外发，保留原报告。

## 3. 外发内容与本地检查分开

Manifest新尾sourceQa固定question、有序sources和本地checks。实际网关只序列化question＋sources，不发送代次／资格检查账本；该完整投影连同全部强制限定计算现有32KiB输入上限和费用，不静默截断。每个source保留固定身份、类型、标题、版本编号、所选字段／绝对范围／原文，以及下表必要上下文。

| 来源 | 强制保留的上下文；不自动附带的内容 |
|---|---|
| 知识 | NOTE／CONCEPT、确切发布版；不展开草稿、双链、关系和其他笔记 |
| 目标／项目 | 类型、标题和用户材料性质；不展开关联项目／事实 |
| 事实 | 本版本责任范围、当前用户确认及父项目状态；不把用户确认当独立技术认证 |
| 表达 | 表达身份及依据复核结论；核对关联事实状态，不附依据正文 |
| 资料摘录 | MANUAL／PARSED、附件身份／SHA、locator、固定run／segment／原选区；不读取文件字节或整份解析结果 |
| 题目 | 完整conditions／technology／scenario；参考答案、检查项和标准正文不参与 |
| 正式回答 | 原答三元组、完整固定作答条件、反馈时机及先前曝光；图标签选区不冒充完整图形，不补读题面或参考 |
| 人工反馈 | 类型、用户录入作者、dimension／coverage、完整condition／basis／limitation及该修订的当前决定；不读引文目标正文 |
| 面后回忆 | RECOLLECTION／NONE基线、题型和完整uncertainty；不编造旧答或提升为正式提交 |
| AI观察 | 固定报告身份、AI_UNREVIEWED、完整报告限制／校验说明／观察condition／basis／limitation及独立决定；不附报告其他观察、summary或citations |

源字段内的指令、链接、角色或提示词都只作资料，不赋予工具、网络、检索或扩大权限的能力。生成结果不成为事实、长期模型记忆、正式知识或能力认证。

## 4. 新外发资格与历史查看

| 来源 | 新预览／发送资格与失效条件 |
|---|---|
| 知识 | ACTIVE当前发布版；固定metadataRevision，改版／归档恢复需重预览；未决影响及既有任务原时间规则见[冻结契约§6](AI知识来源冻结资格契约.md#6-跨域问答显式知识--s8第三十八批) |
| 准备 | ACTIVE当前版及来源代次；事实再要求CONFIRMED、父项目ACTIVE，表达再要求全部事实依据CURRENT |
| 摘录 | 模块启用、READY，SHA及固定解析身份有效；重解析不能替换旧摘录 |
| 题目 | ACTIVE当前题面，固定revision；改版／归档恢复需重预览 |
| 正式回答 | 不可变原答存在且属于本人、会话可读；出现新提交或RUNNING／PAUSED／ENDED推进本身不使旧答失效 |
| 人工反馈 | 原答评价读取许可、当前反馈修订；决定推进要求重预览 |
| 回忆 | ACTIVE当前版及sourceRevision；改版／归档恢复需重预览 |
| AI观察 | 原答评价读取许可，成功任务／尝试／摘要／观察匹配；决定推进要求重预览 |

“可搜索／可查看”不等于“可新外发”。新预览、创建、重试、领取、最终发送和结果接纳沿用途来源校验；不能对整个Search Hit做equals，把动态最新标志或会话状态误当固定条件变化。来源损坏和数据库故障不得降成普通过期。

历史任务和原键回执核固定绑定与当前读取权限，不因正常改版、归档或决定变化重新创建、不重算旧清单。再次发送仍要求原清单的全部新发资格；过时清单须由用户重新选择／预览创建新任务。反馈或AI许可失效必须拒绝正文读取，普通训练资料守卫不是原答评价许可的替代。返回新预览／任务正文前，在独立只读事务再核普通资料条件及来源读取许可；最后网络发送窗口与S8独立最新撤权账本的欠项继续保留。

## 5. API、绑定与兼容

新增SOURCE_QA用途与专用请求，复用Task／Attempt、预算、两协议、通知、单尝试暂态正文、取消／重试／未知费用和持续范围授权；不增加模型SDK、向量库或依赖。

| 方法／路径 | 约定 |
|---|---|
| POST `/api/v1/ai/source-qa/preview` | question、selections；只读RR事务，登录／CSRF／普通资料及原答评价许可，返回既有Preview |
| POST `/api/v1/ai/source-qa/tasks` | 增expectedManifestHash、consentConfirmed=true、可选authorization；原owner命令事务内重建清单、核摘要、保存任务／尝试／有序绑定／通知及回执 |
| 既有 `/api/v1/ai/tasks` | 目录、详情、取消、重试及费用核对沿原路径，新用途历史／流读取补固定来源许可 |

V57只追加新迁移：扩当前task与持续授权用途CHECK，建立一张有序跨域来源绑定表；按域可空类型列、CHECK和owner复合外键固定真实身份，正文只在Manifest，不重复复制。建立来源反向索引供S8影响查询，不改V1–V56。新增读取SQL显式5秒超时；迁移和真实事务仍待服务器。

Manifest第25尾sourceQa、新Task尾sourceQaAnswer／sourceQaManifestHash只用于本用途；三个新字段为空时不输出，响应契约允许缺省而非显式null，旧构造入口和其他用途缺省保持。清单hash及持续授权scopeHash都只省略新增空尾，保留旧用途旧摘要；新scope排除question但固定来源、字段、原文、限定和本地检查。原MATERIAL_QA请求结构、操作路径、回执及引用不改。旧用途拒绝非空新尾，新用途拒绝混入其他专用输入。

新Task携带服务器固定manifestHash供创建恢复核对；客户端不能把含全文JSON的“指纹”当不可逆摘要长留。创建幂等访问guard在回执读取前执行，已签发时核原任务及固定来源身份和许可，不能只在首次action内核对。已签发回执恢复或写入提交后返回前，若读取条件暂不可核实，返回503 AI_SOURCE_QA_RECEIPT_UNAVAILABLE，前端保留原请求／原键；首次执行前明确失败仍用原4xx，不吞数据库及完整性故障。前端未知结果保留原请求／原键，不重发新命令。

## 6. 回答、引用和前端恢复

模型只输出state／answer／limitations／citations；state为SUPPORTED或INSUFFICIENT。SUPPORTED需要1–10项合法引用，INSUFFICIENT引用为空且为有效收费终态，不自动重试。answer为1–12000 Unicode码点，limitations为1–2000，两者及所有quote合计最多24000；quote为1–500码点。拒绝重复键、额外字段、错误类型、截断、工具调用及无完整终态。

Citation为sourceKey／field／start／end／quote，区间使用原字段绝对UTF-16坐标，必须完整位于本次同一所选片段内、逐字匹配且不切代理对；同来源／字段／区间不重复。不引用未选来源、隐藏字段、选区空隙或本地checks。服务器补validationNote，保存结果再次严格读取也复验引用；位置合法不证明语义蕴含或技术正确，全部标为AI未审。

选择、问题、配置变化废弃旧预览和授权；迟到预览按会话／资料／组件请求代次拒收。失权清来源标题／原文及完整预览，保留必要身份和用户输入；恢复后主动重预览，不自动查询。未决创建器始终挂载，锁住选择／问题；失权后迟到成功不缓存完整Task，保留原请求待权限恢复后重核原回执。任务操作的长期回执核对状态只保留SHA-256及必要元数据，异步摘要结束后再次检查权限与请求代次。创建成功展示原任务入口；未知或非法回执不静默当无结果、不另建任务。这里清除的是界面、预览和查询缓存，并拒收迟到结果；不声称能够物理擦除在途HTTP参数或短期计算闭包中的浏览器堆内存。
