# 材料更正的AI制卡出口契约

版本：v1.0 · 2026-11-12。状态：静态检查通过待服务器验收，适用S8第二十八批。承接[材料更正知识影响](材料更正知识影响契约.md)及[AI制卡与采用来源](AI制卡与采用来源契约.md)；实际进度、三组独立静态复核及构建证据见[开发记录](../开发记录/开发阶段与进度.md)。下列服务器场景全部未执行。

## 1. 支持范围

本批仅扩展材料正文更正命令中的`ai_card_draft_source`出口。原材料准入、完整知识采用闭包及其他知识出口限制保持；不扩展材料归档／恢复、撤回／重新允许AI用途，不放行题目、训练、准备、关系、概念组织等其他未支持出口。

制卡来源登记只证明任务输入，不能据此认定已经发送、付费或采用。必须核对真实本人`MEMORY_CARD_DRAFT`任务、原始来源、固定Manifest及摘要和实际决定。无决定或合法IGNORED不产生卡片影响；ADOPTED必须对应本人真实首版卡片，不能使用知识采用决定或伪造目标。

知识影响范围沿真实知识采用目标版号下限判断：确切制卡源版号小于该对象所有实际采用目标的最小版号时，不因本次更正认定受影响。后续版本保守纳入；不以今天知识指针、归档状态或正文相似度隐藏历史登记。

对实际受影响的已采用卡，要求当前卡版仍保留全部原制卡知识来源；可以有新增来源、调整顺序和用户正文改写。原来源被移除或替换则保守阻塞材料更正，返回`MATERIAL_HAS_REFERENCES`；本批不推断剩余正文是否已独立，也不建立取消依赖或真实依据重建流程。

## 2. 固定证明与预算

在原owner命令写锁内，先完成原材料知识闭包和其他出口检查，再执行独立制卡证明，最后核冻结时间并插入V74根。任何不支持、超限、缺史或绑定矛盾均不保存部分声明或影响。

制卡证明包括：

- 原始`ai_card_draft_source`先入核验范围，不通过INNER JOIN、今日状态或决定筛选静默丢弃缺父记录。
- 本人任务真实用途、合法状态及时间；固定Manifest以严格JSON读取，拒绝重复键、尾随值、未知字段、类型强转、数字枚举和空primitive。UTF-8最多131072bytes；用既有`AiManifestDigest`核原摘要，不改写旧JSON／hash／回执，也不要求历史来源今天仍当前。
- `AiSources.validCardDraftInput`及全部1–5个原来源：本人确切知识版、真实kind／版号／标题／完整正文、连续ordinal和完整原顺序均匹配。`materialChecks`须为null；`knowledgeMaterialChecks`兼容历史null或0–200个严格排序、安全修订的检查，不将历史许可代次与今天比较。
- 无决定、IGNORED和ADOPTED分别核形状；存在决定须有真实成功任务及候选、合理决定时序。ADOPTED的目标确切卡版必须为真实首版，类型与原制卡类型一致；原卡题面投影中的来源与原始卡来源登记完整且原序一致。
- 受影响已采用卡的当前本人身份、状态、修订、确切指针／版号、题面投影及原始来源登记一致，且保留全部原知识来源。缺失原卡、错误版本或投影／登记矛盾为完整性错误，不冒充合法空来源。

该证明是原知识闭包之外的独立补充预算：最多200个不同制卡任务、2500条原始绑定，包括发现登记、任务全部来源及原／当前卡来源。原始返回行先计预算，缓存只避免重复查询；查询使用剩余加一，超限409 `MATERIAL_CARD_PROOF_LIMIT`，不返回或保存截断结果。所有新增SELECT显式timeout5，不新增依赖、外部调用或后台进程。

## 3. 失效与历史

不新增迁移、公开接口、响应字段或卡片内容更正事件。继续以V74真实材料更正声明和V75知识影响记录为根及路径，保留现有四类记忆／审阅出口。

完整保留原制卡来源的受影响当前卡，必然具有所引知识版号不早于真实采用目标下限的来源，沿既有`MemoryInvalidation.knowledgeUpstreamChanged`触发待复核、排程暂停及在途回忆失效；根、全部知识影响、卡片／审阅失效和原命令回执同事务。历史评分继续按评分时固定卡版来源判断上游变化，不用今天卡片来源覆盖旧条件。

卡片来源复核、排程显式恢复、知识影响人工处理和AI外发资格仍是独立规则。处理知识影响不恢复旧评分、审阅、授权、卡片排程或旧材料祖先的AI资格。未采用任务的新执行、发送、接纳、采用及重试沿原统一当前性守卫拒绝旧依据；历史清单、候选及费用保留，已经取得网络许可的请求不承诺即时取消。

不从采用历史逆推全部正文派生，也不声称本批能覆盖卡片移除来源后的后代。普通卡片读取不返回参考正文；本次内部证明不读取卡片参考或制造参考曝光、揭示、评分及复习记录。

## 4. 界面与发布

沿用原材料更正入口、知识影响双向目录、逐跳详情和卡片来源复核／历史界面；只同步支持范围与错误说明，不新增自动确认或排程操作。机器契约只调整累计版本及更正相关说明，原请求、响应、操作字符串、Manifest和摘要协议保持。

发布仍须先按顺序显式应用并核验V74／V75，再使用配套后端与前端；本批无新迁移或配置键。不能仅移除SQL阻塞而省略事务中的制卡证明。本机不启动服务、不执行迁移、不调用真实模型、不编写或运行单元测试。
