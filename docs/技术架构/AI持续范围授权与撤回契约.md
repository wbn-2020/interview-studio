# AI 持续范围授权与撤回契约

日期：2026-11-10。版本：v1.0。状态：S5 第三十批静态检查通过待服务器验收，前后端独立静态复核与构建完成；全部运行场景未执行。适用 PRD AI-02、AI-03、AI-06。基础任务、费用与两种供应商协议沿[AI 任务与外发契约](AI任务与外发契约.md)，进度以[开发记录](../开发记录/开发阶段与进度.md)为准。

## 1. 用户行为与范围

用户先完成一条任务的完整预览与明确提交，再从该任务的固定清单创建持续授权。创建授权仅保存许可，不调用模型、不预留费用、不生成候选。授权后每次生成仍主动选择来源、预览实际外发内容、确认并提交；不启用后台自动生成。

一个授权限定同一用途、完整供应商配置及确切来源版本与片段。知识、准备资料、摘录、训练、评价、比较、回忆等分支分别保留自身身份和限定；同一用途的不同来源模式不能相互借用。新增对象、换版、扩大片段、改变反馈决定或来源代次均不能自动进入原授权。主题、文件夹和星图邻居不是动态授权集合。

用户本次填写的 `instruction` 和资料问答的 `materialQa.question` 可以逐次改变，仍需完整预览、计入预算及本次 `manifestHash`。这些文字本身也会外发；授权界面明确说明这一点。其他输入、输出类型、提示版本及本地来源检查均属于固定范围。

供应商边界复用完整配置指纹：包括协议、供应商名称、完整端点、模型、配置／价格修订、币种、单价、额度、超时及协议选项。配置变化需要新授权；不按相同供应商名称推断等价。授权不包含密钥。

## 2. 授权身份、期限与恢复

`ai_scope_authorization` 保存稳定 ID、owner、用途、配置指纹、范围摘要、原任务／清单摘要、进程代次、状态、修订及时间。完整来源继续保存在原任务清单，授权表不另复制正文。目录仅返回用途、公开供应商信息、原任务 ID、摘要、期限和状态；查看完整范围回到原任务并经过原读取守卫。

| 字段／状态 | 规则 |
|---|---|
| `state` | 创建为 ACTIVE，撤回为 REVOKED；没有恢复或重新激活操作 |
| `revision` | 创建为 0，撤回 CAS 后为 1；过期、配置变化和重启不修改持久修订 |
| `expiresAt` | `createdAt + validDays × 24h`，validDays 为 1–90，界面默认 30 |
| `effectiveState` | 按 REVOKED → EXPIRED → RECONFIRM_REQUIRED → UNAVAILABLE → CONFIG_CHANGED → ACTIVE 判断；UNAVAILABLE 表示当前 AI 未启用或配置不完整。缺失授权行或不完整绑定拒绝读取，不伪造单次授权 |
| `runtimeEpoch` | 仅当前进程可用；进程重启后原授权须重新明确创建，不能从数据库的 ACTIVE 自动恢复发送资格 |
| 数量 | 本进程最多 50 条未到期 ACTIVE 授权，目录按 ID 分页，每页 1–50 |

有效状态不代表来源仍可使用；每次预览、创建、发送与接纳继续核对来源、归属及各用途访问条件。来源沿各域现有版本／代次规则：知识仍核 ACTIVE 与确切当前发布版本，本批未新增知识对象用途代次；准备、训练、反馈等继续核各自已有代次。知识归档后恢复同版可能再次符合原许可范围，不等于创建新许可；已撤回、过期或旧进程许可都不会因此复活。

本批的数据库授权与进程代次不能替代[PRD](../需求文档/产品需求文档.md)要求的不随业务备份回滚的最新删除／撤权账本。完整恢复、对象用途撤回及其影响预览仍归 S8；未实现前不声明备份恢复安全已完成。

## 3. 范围摘要与兼容

范围摘要是 `SHA-256("scope-v1\n" + canonicalJSON)`，小写 64 位十六进制。canonicalJSON 从完整 Manifest 仅移除以下字段：

- 顶层 `instruction`、`configuration`、`inputTokenAllowance`、`reservedMicros`。
- `materialQa.question`。

其他字段、数组顺序、空值、来源原文、选区、必要限定、决定、版本和检查代次全部保留。配置由独立完整指纹匹配；预算仍按本次完整投影计算。范围摘要不取代 `manifestHash`，旧 Manifest、Preview、Task、Attempt 响应和原摘要算法保持原规则。

19 个首次任务请求及统一重试请求追加可选 `authorization: {id, expectedRevision}`。缺省或 null 表示单次授权；后端序列化省略 null 尾字段，旧成功命令的 canonical 请求摘要保持兼容。非空引用纳入本次幂等请求摘要。`consentConfirmed=true` 仍表示用户主动确认提交，不能把旧布尔值解释为持续授权。

每个新尝试固定授权 ID／当时修订；无引用的历史尝试仍按原单次授权解释。绑定只在首次插入时写入，费用更新、取消和结果完成都保留它。旧成功原键回放仅恢复回执，不重新建立许可、预留或发送；授权后来撤回不应阻止安全回执恢复，原资料读取守卫仍按原规则执行。

## 4. 事务、发送与撤回

创建授权、绑定尝试、撤回、任务状态及回执均在现有 owner 工作区锁中提交。授权创建核本人可信任务、请求／已存／重算清单摘要、当前配置、绑定、访问条件及来源当前性，不接受客户端伪造清单作为持久授权来源。

`matches` 只根据客户端提供的完整清单返回匹配许可元数据，不读取来源来证明当前性，不创建许可或发送。实际创建任务重新从原请求读来源、重算清单，并在绑定尝试时再核授权；不能仅凭前端匹配结果发送。

| 撤回时任务状态 | 本授权引用下的处理 |
|---|---|
| QUEUED | 转 CANCELED，未发费用 RELEASED |
| RUNNING／VALIDATING | 转 CANCEL_REQUESTED，保留费用、发送记录、令牌和租约；不发布结果 |
| CANCEL_REQUESTED | 保留已有取消请求，不重复释放费用 |
| SUCCEEDED 或其他终态 | 保留既有结果与执行历史；撤回不抹掉已发生调用 |

撤回命令不依赖来源正文可读，不因来源归档、资料守卫或某条清单失效而无法撤回。回执中的 `queuedStopped` 和 `runningStopRequested` 是该次撤回提交时的计数，原键恢复返回同一历史回执。

发送认领、网络前最后检查、后台恢复及结果接纳都核对固定授权。正常撤回、过期或进程／配置变化以安全错误状态处理，不能通过异常回滚已经发生的费用。失败重试另建尝试、重新明确选择授权并预留；旧未知费用确认与账单核对仍独立。

网络前最后检查提交与实际 HTTP 之间存在窗口。撤回后仍可能有已经通过最后检查的请求到达供应商，不能承诺收回已外发数据、供应商立即停止或免费。用量可核算时保留 REPORTED，无法确认时保留 UNKNOWN；迟到用量只补费用，不重新发布结果，也不覆盖人工核对金额。

撤回此条持续授权只作用于引用该 ID 的尝试。其他持续授权或单次授权的任务继续遵循各自许可和取消状态。对象×用途的全量撤回是另一个生命周期动作，不能把本命令的结果描述为全局撤权。

## 5. 接口与界面

机器契约以[累计 OpenAPI](openapi-s7.json)为准。所有端点认证并核 owner；POST 有 CSRF，持久命令有 Idempotency-Key。

| 方法／路径 | 内容与副作用 |
|---|---|
| GET `/api/v1/ai/authorizations` | 安全元数据目录，cursor／limit 分页 |
| POST `/api/v1/ai/authorizations` | `{taskId, expectedManifestHash, validDays, confirmed}` → Entry；从可信任务创建许可 |
| POST `/api/v1/ai/authorizations/matches` | `{manifest}` → `{manifestHash, scopeHash, items}`；只读，无幂等键要求 |
| POST `/api/v1/ai/authorizations/{id}/revoke` | `{expectedRevision, confirmed}` → `{authorization, queuedStopped, runningStopRequested}` |
| GET `/api/v1/ai/tasks/{id}/authorization-uses` | 每次尝试的单次／持续方式、固定引用及当前授权有效状态，无原文 |

上列安全元数据是独立训练资料守卫的精确例外；不是整个 `/ai` 前缀例外。完整任务、来源、评价与历史正文沿原守卫，持续外发授权不代替辅助确认、提前反馈确认或评价区访问。

- 完整预览区共用选择组件，默认单次，持续授权必须主动选中；匹配失败允许用户保留草稿并重新确认单次授权。
- AI 工作区与全局导航提供独立 `/ai/authorizations` 管理页入口，仅显示安全元数据与撤回；独立训练期间或训练状态读取失败时仍可进入，离开保稿守卫保留，受阻正文不显示。
- 任务和训练追问详情可在核对原完整清单后创建持续授权，显示期限与适用边界；逐尝试留痕单独读取。
- 授权过期或变更使旧选择失效，不清除来源、选区或编辑稿；不自动改成另一条授权、不自动发送。
- 未知命令冻结原请求、授权引用和幂等键；迟到成功回执按原请求核对，撤回后也不自动换键再创建。
