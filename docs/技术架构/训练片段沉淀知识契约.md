# 训练片段沉淀知识契约

版本：v1.0 · 2026-11-07。适用：S5 第十三批，PRD KNOW-07、REV-06 的训练片段到笔记／概念子集。状态：静态检查通过待服务器验收；构建证据见[开发记录](../开发记录/开发阶段与进度.md)，接口、数据库和视觉验收尚未执行。

## 1. 业务与来源

用户从一次确切已提交回答选择 1–8 个片段，经外发预览生成待审知识候选。片段可以来自回答文字、图节点标签／说明或边标签；可另选同一提交的一份成功 AI 评价中的 1–5 条反馈。每条反馈保留观察、覆盖状态、条件、依据、限制、建议及原引用，报告限制一并展示并外发。片段与反馈均须明确选择，不默认勾选。固定题目的标题、题干、条件、技术、场景、类型也属于外发清单。

原答是用户当时的表达；评价始终为 `AI_UNREVIEWED`；整理结果是候选。引用逐字一致只证明出处，不认证技术正确、经历真实或用户已经掌握。反馈的接受／争议／忽略和原因不作为本批外发资料，也不随知识采用改变；反馈决定变化不使原报告正文失效。

使用训练题实例中的固定题面和确切 answerId、answerNumber、提交时 answerCondition；不替换成最新答案或题库版本。历史提交在追加答案、暂停、恢复或结束后仍可使用。没有训练来源撤权代次的实现，不虚构代次；完整生命周期仍属 S8。未提交草稿、题库个人参考全文、训练背景、附件、图坐标／外链及未选反馈不自动展开。选定反馈所含的原引用文字会外发，必须在清单中完整显示。

## 2. 请求、清单与引用

沿用 `KNOWLEDGE_DRAFT` 用途和候选／采用决定，新增独立路径，保护旧请求及幂等摘要：

| 操作 | 路径 | 成功 |
|---|---|---|
| 预览 | POST `/api/v1/ai/training-drafts/preview` | 200 AiPreview |
| 创建 | POST `/api/v1/ai/training-drafts/tasks` | 201 AiTask |
| 采用／忽略／重试／取消 | 既有 AI 任务接口 | 沿用原契约 |

预览请求为 `{sessionId,questionId,answerId,instruction,fragments,feedback}`；创建另带 `expectedManifestHash/consentConfirmed`。所有字段显式提供，feedback 可为 null。instruction 保留原文，0–1000 UTF-16 码元，禁 NUL／孤立代理。fragments 为 1–8 项 `{field,elementId,start,end,quote}`；仅允许 `ANSWER_TEXT/ANSWER_NODE_LABEL/ANSWER_NODE_DESCRIPTION/ANSWER_EDGE_LABEL`。TEXT 的 elementId 必须 null，其余为确切图元素 ID；start/end 为原字段的绝对 UTF-16 半开区间，每段非空白且不超过 8000 码元，原文逐字一致，边界不得切开代理对；同字段／元素的区间不可重叠。

feedback 为 null 或 `{taskId,feedbackIds}`；task 必须为本 owner、同一 session/question/answer 的 SUCCEEDED ANSWER_EVALUATION，且已获该回答的评价访问授权。feedbackIds 为 1–5 个不重复且确实存在的报告内 ID。用户决定与原因不会加入输入，原报告不会被改写。

Manifest 尾部增加可空 `trainingDraft`；本类清单为 sources=[]、trainingDraft 非空，其余专用输入均 null，promptVersion=`training-knowledge-draft-1`。旧用途／旧来源拒绝混入该字段，旧历史缺字段按 null 兼容。固定输入包含确切身份、题库来源身份（追问可空）、题面、所选片段、可选报告身份、未审级别／报告限制及选定反馈。32 KiB 限额和费用估算使用与网关相同的 `{purpose,instruction,trainingDraft}` 投影；其他来源不会混入。

模型输出严格为 `{title,sections:[{heading,body,trainingCitations}]}`。复用既有候选限制：标题 1–200 码点、1–12 节、节标题 1–200 码点、每节正文 1–3000 码点且总正文最多 24000 码点，每节 1–10 条引用。引用为 `{field,elementId,start,end,quote}`，field 可为问题题干／条件、四种回答字段、反馈 observation/condition/basis/limitation/suggestion；反馈 elementId 是所选 observation ID。回答引用必须落在已选片段内；问题及反馈引用必须在实际外发字段内。quote 为 1–1000 UTF-16 码元，逐字核验、拒绝重复与代理对中间边界。每节至少一条有效引用。其余引用列表在响应中为空／null，不能将训练身份塞入知识版本引用。服务端回填 validationNote。

## 3. 权限、任务与采用

新路径位于 `/ai`，沿用独立训练资料守卫，包括另一场正在进行的独立训练。评价来源另要求确切回答的评价访问授权；提前反馈确认沿用原评价流程。读取结果、预览响应及幂等回放前仍须检查资料访问条件。后台是否可继续生成与当前是否能查看正文分别处理。

创建、领取、发送、接纳、恢复／重试及采用核对原来源；仅比较已选固定片段、题面和报告内容，不能用最新答案指针、会话 generation 或最新反馈决定替代。正常不可用返回来源失效，数据库错误继续传播。AI 费用、取消、未知状态、配置变更和 SSE 复用[任务契约](AI任务与外发契约.md)。字段错误 400，来源／并发 409，容量上限 422，归属／来源不存在 404；真实错误码以 OpenAPI 及实现为准。

V25 增加独立 `ai_training_draft_source` 关系，记录 owner、AI task、session/question/answer 及可选评价 task，创建任务时同事务保存。关系使用 owner 复合外键；精确片段与选定反馈保存在不可变清单，报告 ID 不能单独替代任务身份。

采用复用[知识候选采用契约](AI候选采用与来源契约.md)：先编辑最终标题／正文，再显式新建 NOTE/CONCEPT 或追加已有知识完整版本；默认 NOTE。已有目标要求当前版本＋草稿修订一致、ACTIVE 且无未发布草稿。来源复核、知识版本／索引 outbox、一次终态决定、修订／通知／回执同事务完成；换键不能重复采用。忽略不要求来源当前，采用不要求 AI 仍启用。采用不改原答、评价、项目事实、关系、回忆排程或复练状态。

知识采用历史新增可空 trainingSource，校验关系与原清单身份一致，显示原题、确切提交、选定反馈及其任务入口。当前不可用不抹掉历史；人工最终正文与原候选分别保留，不声称每句编辑都由原引用证明。其他类型的来源显示及旧回执保持兼容。

## 4. 界面与恢复

训练提交历史和评价任务提供“整理为知识”入口，只携带确切 ID，不发起模型请求。AI 创建页读取保存的原答，用户通过选区／范围选择片段，反馈另行选择。清单完整显示片段、题面、选定反馈的条件／限制／原引文及供应商、费用；修改任一输入撤销预览和同意。

创建和采用复用原键恢复、会话／访问代次守卫、冲突保稿、迟到回执防倒退及页面离开守卫。AI 任务详情显示原候选及可打开出处；知识版本来源能回到确切提交。页面内输入不宣称刷新后持久恢复。视觉体系沿用当前工作区。
