# 资料摘录问答契约

日期／版本：2026-11-07 · v1.1。适用 S5 第八批，状态：静态检查通过待服务器验收；第十批补充资料候选入口的边界说明。承接 [PRD](../需求文档/产品需求文档.md) AI-02–06、[附件契约](附件与安排接口与数据契约.md)及 [AI 任务契约](AI任务与外发契约.md)。实际进度和验证证据仅维护在[开发记录](../开发记录/开发阶段与进度.md)。

## 1. 范围与流程

用户选定附件，在已保存摘录的正文或定位说明中按关键词查找 → 显式选择 1–5 条确切摘录 → 填写问题 → 预览完整外发内容与费用 → 授权本次请求 → 保存带引用或证据不足的 AI 未审回答。检索命中不自动加入发送范围，保存摘录不等于外发授权。原件、整份解析结果、其他附件、准备事实、知识链接和历史问答不会自动附带。

本批检索限于所选附件的已保存摘录，使用转义后的字面子串，不解释通配符；大小写和重音行为沿用数据库排序规则。没有命中时明确显示当前范围为空，可换关键词、选择其他摘录，或明确选择通用解释。跨知识／准备／资料的统一相关性检索、材料自动分段召回、准备建议和训练沉淀继续属于后续范围。

两种模式：`MATERIAL` 仅依据所选资料，资料不足必须说明；`GENERAL` 只发送问题，不发送摘录，结果标为通用解释，不能伪装来自私人材料。切换模式废弃旧预览和授权；不会因无命中、失败或证据不足自动切换模式或再调用。用户手工粘贴在问题中的文字仍会发送，完整预览明确显示。

第十批[附件摘录生成候选](附件摘录生成候选契约.md)复用本篇确切摘录读取与定位规则，以独立入口授权知识整理／出题并显式采用；本篇 MATERIAL_QA 回答仍不提供采用按钮，也不自动转成候选。

## 2. 来源与历史

来源只读数据库中已保存的不可变摘录；校验 owner、附件 READY、原件 SHA-256、确切摘录及解析执行／片段身份。解析摘录保留原运行版本和 UTF-16 范围，手工摘录保持 MANUAL 身份，不冒充解析或核实事实。重解析创建新版本，已有摘录仍指向原执行；附件说明修改不改变引用正文。

`MaterialAiExcerpt={excerptId,attachmentId,fileName,sha256,origin,runId,segmentId,locator,text,startOffset,endOffset}`。不发送附件说明、私有路径、文件字节或其他片段；正文不 trim。MANUAL 的 runId／segmentId／偏移均为 null。来源读取参与外层事务，没有恢复写入、文件 I/O 或解析副作用。

资料域当前没有归档／删除接口，本批不将附件 revision 当作来源代次，也不宣称支持尚未实施的生命周期。后续增加归档、清除或用途撤权时必须扩展来源当前性与在途守卫，不能仅加界面按钮。任务到摘录的关系单独持久化，为影响查询保留确切身份，不依赖扫描清单 JSON。

MATERIAL 预览／创建要求资料模块启用；发送前和接纳前模块关闭或来源失效，走 `AI_SOURCE_CHANGED` 及原费用规则。数据库故障不能伪装成来源撤回。GENERAL 不依赖资料模块；解析器关闭不阻断已保存摘录。历史清单与回答按任务权限保留，来源失效不赋予重新发送资格。

## 3. 清单、授权与接口

新增 `Purpose=MATERIAL_QA`，复用现有 Task／Attempt、预算、通知、取消、重试和账单核对，不产生知识／题库采用决定。两个模式和全部读写仍受独立训练资料守卫约束，无新增豁免。

- `MaterialQaPreviewRequest={mode,question,excerptIds}`：mode 必填 MATERIAL／GENERAL；question 去除首尾空白后 1–2000 UTF-16 码元，禁止 NUL。MATERIAL 为 1–5 条不同的合法摘录 ID；GENERAL 为明确的空数组，不接受隐含资料。
- `CreateMaterialQa` 增加 `expectedManifestHash` 和 `consentConfirmed=true`，使用专用请求类型及操作路径，保留原有创建请求与幂等摘要语义。
- `AiManifest` 追加可空 `materialQa={mode,question,excerpts}`；该用途的 instruction 为空、sources 为空、training／evaluation／contextChecks 为 null。promptVersion=`material-qa-1`，整个固定清单参与授权摘要。其他用途及旧清单缺字段时为 null，不能填成新的资料来源。
- 实际输入最多 32 KiB，不静默截断，费用预留沿用现有字节额度及协议余量。网关只发该用途的明确输入，不序列化整份 Manifest；资料中的指令、链接不能改变工具、检索、权限或费用范围。

| 方法／路径 | 约定 |
|---|---|
| GET `/api/v1/materials/attachments/{id}/excerpts?q=&cursor=&limit=20` | 在既有分页上增加可选 q，去除首尾空白后最多 100；空值列出已有摘录，非空检索正文或定位；无模型／费用副作用 |
| POST `/api/v1/ai/material-qa/preview` | 只读外发预览，需登录／CSRF／资料守卫；返回现有 Preview |
| POST `/api/v1/ai/material-qa/tasks` | 原幂等键、owner 锁内重读来源／配置／清单摘要及预算，201 返回现有 Task |

任务列表、详情、取消、重试和费用核对沿用 `/api/v1/ai/tasks`。创建、重试、排队恢复、领取、最终发送和接纳都核验用途对应来源；不在数据库锁内等待模型。已发送后失效保留实际／未知费用，不以抛业务异常回滚费用事务。新结果不自动写入知识、事实或永久模型记忆。

## 4. 回答与引用

`AiTask` 追加可空 `materialAnswer={state,answer,limitations,citations,validationNote}`；旧回执和其他用途为 null。模型只输出 state、answer、limitations、citations，validationNote 由服务器生成；拒绝重复键、未知字段、错误类型、截断、工具调用和不完整响应。

- state 为 `SUPPORTED|INSUFFICIENT|GENERAL`。MATERIAL 只允许前两者；SUPPORTED 需要 1–10 项合法引用；INSUFFICIENT 的引用为空，是有效终态回答，仍计费用，不自动重试。GENERAL 只允许 GENERAL，输入摘录和输出引用都为空。
- answer 为 1–12000 Unicode 码点，limitations 为 1–2000；两者及所有 quote 合计最多 24000 码点。必须说明所查范围和局限，不补造用户经历或声称检索过其他材料。
- `MaterialCitation={excerptId,start,end,quote}`：只能引用清单中的确切摘录；区间为摘录正文内的 UTF-16 `[start,end)`，非空、不切开代理对，quote 为 1–500 码点且逐字等于原文。相同摘录与区间不能重复。
- 页面展示引用片段、对应定位、手工／解析身份，并可打开完整确切摘录；原件已解析时保留原 run／segment 身份。位置校验只证明结构和定位合法，不能证明语义蕴含、技术正确或项目事实真实；SUPPORTED 也必须标为 AI 未审。

新模型用途沿用已实现的非流式 Chat Completions／Responses 请求和严格结果解析；本批不修改第三方协议，不添加 SDK、嵌入服务或依赖。真实供应商兼容及回答质量仍待服务器验证。

## 5. 前端恢复

复用现有组件、任务中心和状态查询。选择、模式、问题或配置变化立即清除旧预览和勾选，并拒收迟到预览。错误、断网、重新登录及资料守卫变化保留问题和已选来源；创建未知响应只恢复原请求／原键，不自动发起新任务。取消、重试和费用表单继续沿用既有恢复规则。

关键词变化重置摘录分页；当前选中附件限定搜索范围。检索词不会冒充问题，也不作为隐藏上下文发送。通用解释和资料问答在输入、清单与结果中均有明确标签；不会把结果当知识候选显示采用按钮。
