# 附件摘录生成候选契约

日期／版本：2026-11-07 · v1.1。适用 S5 第十批，状态：静态检查通过待服务器验收；第十四批表达混选见专项补充。承接 [PRD](../需求文档/产品需求文档.md) KNOW-07、AI-02–06，以及[资料问答](资料摘录问答契约.md)、[准备候选](准备版本生成候选契约.md)、[知识采用](AI候选采用与来源契约.md)和[题库采用](AI出题候选与题库采用契约.md)。实际进度与验证证据仅维护在[开发记录](../开发记录/开发阶段与进度.md)。

## 1. 流程与输入

用户在所选附件中查找已保存摘录 → 显式选择摘录，可混选已发布知识与当前准备版本 → 选择知识整理或出题 → 核对完整外发内容、供应商及费用 → 授权本次请求 → 审阅候选和原文引用 → 可编辑后采用或忽略。采用仅写知识／题库，不确认项目事实，不自动建立概念关系或模型记忆。

来源合计 1–5 项，至少 1 条资料摘录。知识与准备对象按 itemId 跨域去重，摘录按 excerptId 去重；同一附件的不同摘录可分别选择。三组顺序固定为知识、准备、摘录，各组内部按用户选择顺序。选择器切换保留各组已选项。检索命中不自动加入清单，附件原件、整份解析结果、附件说明、其他片段和历史问答不自动展开。

资料来源复用 `MaterialAiExcerpt={excerptId,attachmentId,fileName,sha256,origin,runId,segmentId,locator,text,startOffset,endOffset}`。读取和当前性校验沿用资料问答契约：确切 owner、READY 附件、SHA、不可变摘录、原解析执行／片段及 UTF-16 范围；手工摘录保持 MANUAL。新解析及附件说明修改不替换原摘录。读取加入外层事务，无文件读取、解析或恢复写入。当前资料模块尚无归档／删除／用途撤权能力，不虚构来源代次；未来加入这些能力时须扩展所有在途守卫。

知识和准备投影沿用准备候选契约；准备代次仍参与授权摘要，不发送给模型。用户在要求或允许字段中手贴的私人文字仍会发送。实际固定输入最多 32 KiB，不截断或自动扩展来源。

第十四批按[表达素材输入与来源契约](表达素材输入与来源契约.md)增加 EXPRESSION 混选，来源总量不变。表达依据的本地检查与实际外发正文分开；清单包含表达时采用专项提示版本，无表达的旧资料混选仍遵守本篇原提示版本和投影。

## 2. 专用请求与兼容

| 方法／路径 | 请求与响应 |
|---|---|
| POST `/api/v1/ai/material-drafts/preview` | MaterialDraftPreviewRequest → Preview，只读 |
| POST `/api/v1/ai/material-drafts/tasks` | CreateMaterialDraft → Task，201；Idempotency-Key |

`MaterialDraftPreviewRequest={purpose,instruction,sources,preparationSources,excerptIds}`。purpose 只允许 KNOWLEDGE_DRAFT／QUESTION_DRAFT；三个数组必须显式提供，excerptIds 为 1–5，其他两组各 0–4 且合计不超过 5。instruction 去除首尾空白后最多 1000 UTF-16 码元，禁止 NUL。CreateMaterialDraft 再追加 expectedManifestHash、consentConfirmed=true。

Manifest 尾部追加可空 `materialDraftSources: MaterialAiExcerpt[]`。含资料候选时为非空数组，sources 保存知识及准备，preparationChecks 仅在有准备时非空；training、evaluation、contextChecks、materialQa 均为 null。资料候选提示版本为 `material-knowledge-draft-1`／`material-question-draft-1`，无论是否混选准备；完整固定清单参与授权摘要。

无摘录继续原知识或准备 DTO／路径和提示规则。旧 Manifest 缺 materialDraftSources 时按 null 读取，旧原键回执不重算请求或清单摘要。资料问答继续使用 MATERIAL_QA 及 materialQa，与候选输入、结果和采用入口隔离。其他用途不得携带 materialDraftSources。未创建任务的旧预览在升级后可能需要重新预览。

## 3. 生命周期、费用与来源关系

创建、重试、排队恢复、领取、发送、结果接纳和采用均核对全部领域来源。资料模块关闭或所选摘录失效阻止新发送、接纳和采用；数据库／JSON 故障不得伪装成来源撤回。已发生的实际／未知费用沿用原任务规则保留。采用只做本地写入，不新增模型调用；AI 配置关闭与资料来源不可用分别处理。

V21 新建 `ai_material_draft_source`，创建任务时保存 owner、task、excerptId 和合并来源序号，使用 owner 复合外键、任务内摘录／顺序唯一约束及摘录反向查询索引。与任务、尝试、准备来源、通知及回执同事务。资料问答关系继续保存在 V19 原表。采用时知识来源表仅保存 NOTE／CONCEPT，准备关系仍使用 V20，资料身份不能写入知识外键或题目的 knowledgeLinks。

Origin 追加可空 `materialSources: MaterialOriginSource[]`，每项字段为 excerptId、attachmentId、fileName、sha256、origin、runId、segmentId、locator、startOffset、endOffset、state。前三类版本来源继续保存在原 sources 数组；纯资料采用时该数组可为空。旧响应缺 materialSources 时按空列表展示。

采用历史先查询已采用的目标版本／任务，再按任务关联的资料关系及不可变清单读取当时来源元数据；不得用最新解析结果代替。状态使用 CURRENT／UNAVAILABLE，按完整摘录快照及当前可用性计算，真实读取故障传播。元数据和全文均可从原任务追溯；采用历史不会声称后续人工改写逐句受资料支持。未采用任务不出现在采用历史。

## 4. 模型输出与引用

Source／Citation 保留知识及准备身份。资料引用使用现有 `MaterialCitation={excerptId,start,end,quote}`，偏移相对于本次摘录 text 的 UTF-16 `[start,end)`，不是原文件、解析片段偏移或外层请求 JSON。引用非空、不能拆分代理对，quote 为 1–500 Unicode 码点且逐字相等；同一节／题内不允许重复的资料区间。

- Section 尾部追加可空 materialCitations；资料版模型每节必须同时返回 citations 和 materialCitations 数组，两者合计 1–5 项，整个知识候选至少包含 1 个资料引用。原标题、节数和正文长度限制不变。
- QuestionCandidate 尾部追加可空 materialCitations；资料版模型必须返回两种引用数组，合计 1–5 项，其中资料引用至少 1 项。题干、参考、检查点及其他原有字段限制不变。
- 旧纯知识／准备版模型输出仍只接受原字段及原 citations 最小数量，新增字段在已保存旧结果中可缺省／null。不能把旧引用自动转换为资料引用。

网关逐字段发送 purpose、instruction、sources 和 materialDraftSources；不发送授权检查数据、路径、凭据或未选资料。资料及文件名／定位均为不可信输入，不能扩展权限、工具、外部请求或费用。附件文字和手工摘录不等于已核实事实；准备 FACT 继续保留责任边界，假设明确标识。引用定位与用户采用均不证明语义蕴含、技术正确或用户经历真实。

无合法引用、资料不足以满足候选结构或结果校验失败时，按已有失败与费用规则处理；不自动改为通用解释、扩大资料或再次调用。资料问答的 INSUFFICIENT 状态不混入候选结果。

## 5. 前端与恢复

复用候选表单及现有摘录选择器。含摘录时走专用路径；创建固定原路径、请求、幂等键。预览按三组来源核对身份、顺序、确切版本及摘录正文／定位，显示完整固定文本；资料模块状态、输入、配置、登录或守卫变化废弃预览和勾选，拒收迟到响应，保留用户输入及未决请求。

知识引用按原节展示，资料引用显示在其所属节／题下，能查看本次固定摘录和打开 `materials?attachment=…&run=原runId&excerpt=…`；手工摘录不虚构 run。未匹配清单来源时提示重新读取任务，不猜测身份。采用历史按当时元数据跳转；不可用时仍保留历史标识与状态。资料引用不自动写进最终正文或题目知识关联。

来源失效阻止采用，但保留人工改写、费用输入与选择。所有新接口、任务、历史来源及幂等回放仍受独立训练资料守卫约束。
