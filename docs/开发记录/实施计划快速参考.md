## 🚨 风险预警与应对

### P0 风险（概率 >30%）

| 风险 | 触发条件 | 预警信号 | 应对 |
|---|---|---|---|
| **用户反馈变更** | W2 完成后新需求提出 | 反馈中出现"之前没想到的" | 冻结需求，推迟到 S2 |
| **算法验证失败** | 成功率 <70% | W2 中期测试不达标 | 准备备选方案，重试 |
| **部署失败** | 生产环部署有问题 | W11 前两天无法启动 | 回滚、本地复现、改进 |
| **核心功能超期** | 某个 API 花时间 >2 倍预期 | W6/W7 周四仍未完成 | 简化功能范围 |

### P1 风险（概率 10-20%）

| 风险 | 触发条件 | 应对 |
|---|---|---|
| 框架不兼容 | 依赖升级出现兼容性问题 | 降级或用备选框架 |
| 性能达不到目标 | W9 性能测试 >500ms | 优化 SQL + 加索引 |
| 人员临时离职 | 团队成员请假 > 1 周 | 交叉培训、知识文档化 |
| 代码质量下滑 | 代码审查通过率 <80% | 暂停新功能，补代码审查 |
