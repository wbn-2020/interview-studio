日期：2026-11-16。适用范围：本仓库本地前端静态构建包与 `.cache/` 分类。状态及本次迁移结果见[开发阶段与进度](开发阶段与进度.md)；本文件不表示视觉验收通过。

## 目录

```text
artifacts/

│   ├── dist/

```

`frontend/` 保留源码、工程配置、依赖及维护脚本；`artifacts/frontend/` 只放可上传的静态构建包，每包包含自己的HTML入口和assets。包名继续保留原日期／批次，不将多个包的assets混合。整个 `artifacts/` 由Git忽略，不提交生成包。

## 构建输出

Vite默认输出位置为 `artifacts/frontend/dist-<UTC时间>/`，自动按毫秒生成独立目录，保留已迁移的历史 `dist/`。正式批次显式使用尚不存在的独立目录。例如，在仓库的 `frontend/` 绝对工作目录执行：

```powershell
node.exe --max-old-space-size=1024 node_modules/vite/bin/vite.js build --outDir ../artifacts/frontend/dist-studio-v12-20261114-r101
if ($LASTEXITCODE -ne 0) { throw '前端构建失败' }
```

执行前检查确切目标目录不存在，不复用上例批次名。类型检查仍按原工程方式单独执行；本地不启动服务，不新增或运行单元测试。静态检查、构建和上传流程均须读取本批实际输出路径及SHA清单，不能仅凭文件夹名判断版本。

## 历史包定位

原路径 `frontend/<包名>/` 统一迁移为 `artifacts/frontend/<包名>/`，其中 `<包名>` 为原 `dist` 或 `dist-*` 目录名。历史文档、清单、部署日志中记录的原路径保留当时事实，不批量改写历史证据；查找实际文件时按本映射定位。

本次迁移清单保存在 `artifacts/records/frontend-move-20261116-plan.json`，完成记录保存在同目录 `frontend-move-20261116-result.json`。清单逐包记录原／新路径、逐文件相对路径、字节数和SHA256；迁移后重新读取全部文件核对，同时核对文件夹名、目录结构和源路径退出情况。

前端包迁移不移动源码、依赖、文档、后端制品、验收截图或服务器目录；缓存内历史制品和图片的分类另见下文。不删除、压缩或重新生成历史包。迁移出现目标冲突、重解析点、内容变化或部分失败时立即停止，保留记录，按已核实的单包状态处理。

## 缓存分类

`.cache/README.md` 是本地分类入口。零散内容按用途放入以下目录，保留原文件名、批次和各证据目录内部结构：

| 目录 | 用途 |
|---|---|
| `build/frontend/`、`build/backend/`、`build/contracts/` | 构建清单、日志、编译／类型／schema中间产物和历史制品 |
| `visual/replica/` | 固定参考态服务器截图、叠加、差异和交互记录 |
| `visual/formal/` | 正式业务页面的运行／截图证据 |
| `visual/diagnostics/`、`visual/images/` | 临时诊断、候选及独立图片证据 |
| `verification/` | 静态结果、保护基线、日志与协作说明 |
| `deployment/records/` | 部署审计、上传清单及服务器读回记录 |
| `git/records/` | Git提交／暂存／差异检查记录 |
| `scripts/active/` | 当前使用的构建、发布、采集辅助脚本 |
| `scripts/build/`、`scripts/visual/`、`scripts/verification/`、`scripts/deployment/`、`scripts/git/` | 按用途分类的历史脚本 |
| `maintenance/` | 整理清单、逐文件核对和路径查找工具 |

已有 `maven/`、`npm/` 依赖缓存及独立私有 `deployment-20261113/` 目录维持原位。本次不读取或改动私有部署目录内部的凭据，不连接服务器，不改动运行服务。

缓存旧新路径及逐文件校验范围在 `.cache/maintenance/cache-layout-20261116-plan.json`，完成记录在同目录 `cache-layout-20261116-result.json`。同卷移动前后核对目录、文件名、大小与修改时间；脚本、清单、日志等小文件同时核对SHA256，PNG、JAR、BIN及大于16MiB文件仅核对元数据，不宣称缓存全部二进制逐字节复验。前述146个前端构建包仍是全部文件SHA256核对。原始证据内容不改写，历史脚本不得直接当作当前工作流执行；当前脚本已更新分类后的依赖路径。需要定位旧引用时，在仓库绝对工作目录使用：

```powershell
node.exe .cache/maintenance/cache-paths.mjs .cache/v12-server-review-20261114-r100-full/results.json
if ($LASTEXITCODE -ne 0) { throw '缓存路径查找失败' }
```

后续新产物直接写入相应类别，不再次堆放在 `.cache/` 顶层。迁移清单及历史日志是追溯材料，不在本次整理中清理。
