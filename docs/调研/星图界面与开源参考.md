## 1. 结论与证据范围

推荐保留“个人知识宇宙”的探索感：从连续图谱选择知识点，在侧栏展开笔记、题目、项目事实与训练证据；阅读、写作和独立作答使用稳定、清晰的工作区。光效用于强调当前关系，不能用连线数量、闪烁或星球大小暗示知识掌握程度。

本次事实分四层：

- **用户提供：**两段视频文字介绍及其链接，包含光球／花状元素、水母、发光连线、点击展开和多轮迭代的描述。
- **已核验：**GitHub 官方 API 返回的 README、清单、许可证和部分关键源码；Obsidian 官方帮助源文件；Refero 的页面标题。
- **基于源码的推断：**这些实现可以启发分层探索和旁侧详情，但不能直接证明中文长答可用性、性能、移动端效果或学习价值。
- **尚未验证：**视频实际画面、参考应用运行效果、完整无障碍表现、真实库大规模性能、第三方媒体权利链及服务器部署效果。

`web.run` 已尝试访问，但本轮未返回可用正文，空返回不作为证据。随后使用 PowerShell 7 的 `Invoke-WebRequest`／`Invoke-RestMethod` 对公开 URL 进行只读核对。GitHub 内容通过官方 API 的 `application/vnd.github.raw+json` 读取，并按 UTF-8 作为文本查看；没有执行获取到的代码或脚本，没有下载视频、安装依赖或启动服务。

### 3.2 必须区分的关系语义

`graph.js` 的“共振”来自两份内容共同命中至少两个概念词，并添加两个方向的连接。它不是作者分别在两篇笔记中主动建立的引用。[V08]

问阶不应复制这一语义混用：

| 关系 | 问阶建议的来源 | 展示规则 |
|---|---|---|
| 笔记正文引用 | 用户插入的明确对象链接 | 保留方向、出处与反向查询；反链不是自动新增一条正文引用 |
| 概念关系 | 用户定义或确认的前置、组成、比较、应用等关系 | 方向、类型及创建来源可查 |
| 主题归属 | 用户选择的多个主题 | 作为筛选或分组，不自动生成同主题节点间的全连接 |
| 训练证据 | 已提交回答、反馈、复练的确切版本引用 | 点击进入对应原文；不是一般知识论断 |
| 相似／共同提及 | 检索规则或 AI 提出的候选 | 独立候选层；说明依据，未经采用不进入正式语义关系 |
| 画布连接 | 用户用于表达思路的视觉线 | 默认只属于该画布；转为知识关系必须另有明确操作 |

这张表是问阶的新设计建议，不是对参考仓库的功能描述。

## 5. Obsidian 主题、图谱与画布应分别借鉴

官方帮助将 Graph view 定义为笔记及其内部链接的图形显示，并提供聚焦当前笔记的局部图；Canvas 则允许摆放笔记、附件和独立文字卡片，保存为 JSON Canvas。独立文字卡片与源笔记并非同一个对象。[V19]

问阶应提供三个共用内容的入口：

1. **知识列表／编辑器：**长文阅读、筛选、写作与内容管理。
2. **知识星图：**概念关系探索、跨主题发现、原文和训练证据导航。
3. **脑图／白板：**组织面试提纲、项目链路和方案推演；节点布局与线条不自动改变知识语义。

官方 Themes 与 CSS snippets 文档描述的是外观配置及样式扩展；主题、插件和知识数据是不同层次。[V20]

## 6. 转译为完整产品的知识星图

以下全部为新建议，供完整产品文档采用，不是外部项目已证明的效果。

### 6.1 视觉与信息层级

- 保留全站稳定导航；“知识”进入星图时使用深色宇宙画布，编辑器和训练页面保留可独立选择的阅读主题。认可暗色银河不强制全站深色。
- 默认显示知识点，主题是星域或筛选条件。一个知识点只保留一个身份，可以属于多个主题。
- 笔记、题目、事实、回答、反馈、复练记录按需展开，避免初次打开就把所有类型堆进同一屏。
- 水母、光球或花状装饰用于主题识别与氛围，不承担唯一点击命中区；实际目标有稳定标签、焦点和可点击轮廓。
- 发光主要表达选中节点、当前探索路径与正在查看的关系。连接粗细、大小若映射数量，必须有图例和统计口径。
- 无关系的知识点如实显示为未关联，不为了“全图连通”添加虚构连线；真实已有关联不能因主题切换被割裂。

### 6.2 探索与编辑

1. 从搜索、列表或主题进入同一个知识对象，保留搜索词及返回位置。
2. 选择“缓存一致性”，高亮其跨主题关系，在右侧显示概念摘要、主笔记、相关题目、项目事实及训练证据。
3. 点击连线能看到关系类型、方向、创建来源；若来自笔记正文，能定位对应出处。
4. 展开邻居或切换主题只改变可见性与镜头；保持已有节点世界坐标。主动重新布局是独立操作，提供预览及撤销。
5. 编辑主笔记修改同一份源正文并产生版本；从白板移除卡片不删除源笔记。
6. 点“练这一点”进入空白独立回答；训练结束后允许选择有来源的片段生成知识候选，采用前可编辑。
7. 回到星图恢复视口、选中项及探索路径；详情面板可关闭，不迫使用户重新找节点。

### 6.3 少动效与大图退路

- 提供“完整／轻量／静止”显示选项，尊重系统减少动效；静止模式保留所有业务信息与操作。
- 背景粒子、循环媒体、漂浮、呼吸光效均可关闭；阅读与输入时默认减弱装饰，隐藏标签页暂停动效。
- 优先确保节点与文字清晰，再增加氛围。低配置时使用二维节点、普通边和列表，不将 WebGL 支持作为知识可访问的前提。
- 大图提供主题过滤、邻域深度、渐进展开、结果数量提示与列表查询；不能默认一次加载全部笔记正文。
- 键盘可搜索、选择、打开详情、返回；焦点不会被动画移动。窄屏采用列表／局部图与详情切换，保留同一对象身份。
- 中文长标题、同名概念、无结果、断链、归档来源、关系很多的节点和加载失败都要有明确状态。

### 6.4 服务器验收时需要观察的实例

| 场景 | 验收观察点 |
|---|---|
| 同一概念属于缓存和分布式两个主题 | 切换主题保身份和位置；跨主题边仍可发现 |
| 从原回答打开关联笔记，再进入复练 | 能返回确切原文；复练不带入旧答案 |
| 一个概念有许多笔记、少量真实关系 | 图不伪造大量语义边；列表可分页或分段查看 |
| AI 推荐“缓存一致性前置于分布式事务” | 显示为候选，说明依据；未确认不写入正式关系 |
| 关闭全部动效或使用键盘 | 业务信息、标签、侧栏和返回操作完整可用 |
| 拖动、刷新、切换主题后返回 | 服务端已保存的坐标与视口能够恢复；并发冲突明确处理 |
| 白板删除一个笔记卡片 | 原知识笔记及其他引用仍存在 |

这些是待执行验收场景；本轮不启动本地服务，也未对参考项目或问阶执行浏览器验收。
