## 1. 结论先行

**整体方向合理，完整产品的模块覆盖较充分；需要补的是模块之间的具体规则和若干设计／契约偏差，而不是继续堆功能或重做技术栈。**

- 独立知识库、概念／笔记分层、真实语义关系、原答不可变、用户事实核实与外发授权分离、AI 候选显式采用、空白复练与历史条件对照，都是值得保留的核心设计。
- 本轮记录 **13 项问题或完善建议：12 项 P2、1 项 P3**。交付复核时 AUD-02 已由并行开发更新同步，不再计为当前未解决问题；因此仍待处理的是 **12 项（11 项 P2、1 项 P3）**。其中有确定的文档／静态契约偏差，也有尚未实施模块的规则细化，不能把它们全部表述成当前功能故障。

### AUD-05 · P2 · “字符”限长单位不一致

**证据：**[PRD](../../需求文档/产品需求文档.md) `:509` 给 Unicode 字符目标；`TrainingInput.java:139–143` 用 `codePointCount`；`TrainingAnswerEditor.vue:114–123、298` 用 JS `.length` 并据问题禁用保存／提交；`KnowledgeService.java:489、494` 仍按 UTF-16 长度。

**已有覆盖／残留：**后端有上限，普通中文 BMP 字符计数一致；补充平面汉字、emoji 的 UTF-16 单元和码点数不同。静态推演：10,001 个单码点 emoji 为 20,002 个 UTF-16 单元，训练前端超限，而后端码点数未超 20,000。未发请求，不声称已观察到运行失败。

**最小建议：**统一业务限长单位，建议沿用训练／AI 已有 Unicode 码点口径，界面计数与服务端一致；结合字节容量另行守卫。**引用偏移仍按已约定的 UTF-16 区间，不能一起改成码点偏移。**

**服务器验收：**混合中文、emoji、补充平面汉字进行边界粘贴、保存、提交；计数、接受／拒绝、返回原文及引用位置一致，不静默截断。

### AUD-08 · P2 · 动作采用后需要可信的退出追踪路径

**证据：**[PRD](../../需求文档/产品需求文档.md) `:145、262–275、427`；[架构](../../技术架构/系统架构与数据边界.md) `:125–126`。取消安排不取消动作，结论为已处理／部分／未处理／无法判断。

**已有覆盖／残留：**来源独立判断、忽略反馈、延期保留来源均正确；动作采用后因目标变化、原反馈不适用或用户决定不继续投入而退出，没有明确状态。取消安排不是退出动作，“已处理”又会虚构完成验证。

**最小建议：**来源可显式“归档／不再追踪”，留原因，不等价于已处理。多来源只退出所选来源；保留历史结论与复练，恢复显式操作，完成统计与推荐区别此状态。

**服务器验收：**合并动作含 A／B 两来源，仅退出 A：A 不再推荐，B 保持有效，完成数不增加；恢复 A 不重置历史或关闭 B。

### AUD-09 · P2 · 共享任务多截止日期的改期冲突需有默认规则

**证据：**[PRD](../../需求文档/产品需求文档.md) `:146、157、282`；[附件与安排契约](../../技术架构/附件与安排接口与数据契约.md) `:67` 明确当前 S3 只改面试安排／提醒，准备任务后续接入。

**已有覆盖／残留：**任务身份去重、未开始改期预览、完成记录不移、手工锁定均已定义；同一任务服务多目标／多面试时有效期限如何计算未明确。S3 不移动未来任务是阶段边界，不是当前改期故障。

**触发：**同一缓存复练服务周二与周五面试，周二延期至下周，不能整体后移越过周五，也不能复制任务绕过去重。

**最小建议：**自动建议参考最早有效截止日期；用户锁定日期优先，冲突只提示。预览展示所有期限来源、有效日期变化和未移动理由；取消一场只移除该期限约束，不关闭动作。

**服务器验收：**两场共享一任务，延期较早场后仍一条任务且受另一场约束；取消／移除一来源不关闭动作，锁定与完成记录保持，预览解释清楚。

### AUD-10 · P2 · 回忆自评要区分回想成功和揭示后眼熟

**证据：**[PRD](../../需求文档/产品需求文档.md) `:224` 为“忘记／困难／记得／熟悉”；[既有调研](../../调研/知识管理与复习调研.md) `:129` 已建议“忘记／费力想起／正常想起／轻松想起”。Anki 官方说明 Hard 是成功等级。

**已有覆盖／残留：**先想后揭示、固定版本、同次幂等、事件与排程同事务、自评不是技术审核都已覆盖；正确等级文案仍停在调研稿，没有在主规格明确算法映射。“熟悉”容易被理解成揭示后眼熟。

**最小建议：**采用已有文案，失败为未回想成功；其余分别是成功但费力、成功有少量犹豫、成功且轻松。明确“看答案后眼熟不算成功回想”，由用户选，不由模型猜。复习自评不等于自由答案技术正确。

**服务器验收：**等级解释与原始 rating／算法映射一致；揭示后仍明确要求按揭示前回忆判断，浏览／跳过不产生成功复习事件。

### AUD-11 · P2 · 延期与排程更改不能混成一个动作

**证据：**[PRD](../../需求文档/产品需求文档.md) `:145、226、426`；[选型](../../技术架构/技术选型与决策.md) `:202` 允许明确排程方式的人工指定日期。

**已有覆盖／残留：**移出今日不抹到期、暂停退出队列、恢复显式启用、历史不重写已有规定；“延期”究竟暂缓显示、人工覆盖日期还是重新算间隔，仍可能不同。预算耗尽时新卡、到期旧卡、同日重学的优先级也需明确。

**最小建议：**分开算法到期、队列暂缓、人工改期，展示来源与原因。延期／暂停不生成成功回忆，不伪造学习时刻；真实复习按实际时间计算。预算只限呈现数量，不让到期债务消失，明确积压时的新卡策略。

**服务器验收：**延期、移出今日、暂停、恢复、人工改期分别检查事件、原算法依据、展示日期；额度耗尽仍能查剩余，到期／重学／新卡顺序符合明确规则。

### AUD-12 · P2 · 可访问性总原则需落到复杂动作与状态验收

**证据：**[交互规格](../../交互设计/知识星图与工作台.md) `:113–114、178、182、186` 已有显式按钮、40／44 px 目标、方向按钮、焦点返回和窄屏；[S2 契约](../../技术架构/知识工作区接口与数据契约.md) `:80` 枚举拖动、键盘移动、连线、分组等，但未逐项规定非拖动等效流程。

**已有覆盖／反证：**不是“没做无障碍”，也不是缺目标尺寸。现存训练问题提示已使用 `role="status"`，不能一概称没有辅助技术支持。残留在建立／改接连线、分组、排序等复杂动作的点击／轻触替代，和保存状态、抽屉切换的完整验收契约。

**最小建议：**将动作列成等价矩阵，例如点选两端创建线、选择目标父节点、上移／下移排序、菜单分组；仅键盘替代不能满足 WCAG 2.2 的单指非拖动条款。明确异步保存的可编程状态和适度播报，不把每条提示都做成强警报；验证模态焦点、侧栏打开／缩窄后的焦点与原触发项返回。

**服务器验收：**只用点击／轻触而不拖动完成相同动作；再独立检查纯键盘、读屏保存反馈、焦点遮挡与窄屏。WCAG 来源只是验收依据，不是本轮合规认证。

### AUD-13 · P3 · 截断路径检查不能说成确定“无路径”

**证据：**[S2 契约](../../技术架构/知识工作区接口与数据契约.md) `:54` 返回 found／truncated；[交互规格](../../交互设计/知识星图与工作台.md) `:170` 显示局部加载数量和限制。

**已有覆盖／残留：**真边、方向、检查上限、截断与继续入口均有；未明确 `found=false,truncated=true` 的结论应是“检查未完成”。局部窗口也不能代表全局查询范围，未完成搜索不能称已证明最短。

**最小建议／验收：**区分找到、在指定范围未找到、检查未完成，展示类型／方向／状态范围。窗口外路径用完整文字列表或按需展开查看，不重排旧坐标；服务器验证截断时不显示确定无关联。
