## FAQ

### Q1：是否一定要完成所有 P0 问题才能开工？
**A**：是。这五个问题是系统性的，不能部分完成。开工前必须对这五个问题有明确决策。

### Q2：冷启动验证会不会太慢？
**A**：不会。招募 + 问卷 + 整理只需 2-3 周。与"6 个月后发现方向错误"相比，这个成本很低。

### Q3：能否先做 S1 其他部分，P0 问题后补？
**A**：不行。P0 问题的决策会影响 S1 的 DDL 设计（例如"简化架构"会删除多个表）。开工前必须确定。

### Q4：如果冷启动验证发现需求完全不同怎么办？
**A**：那就改 PRD 和架构。这是"验证"的目的。延期 2-4 周总比"6 个月后推倒重来"好。

### Q5：引文定位算法的 20 例验证会不会占用太多时间？
**A**：验证本身很快（调用 API 比较结果）。困难的是"设计方案"和"编写提示词"，这个 1-2 周是必要的投入。
