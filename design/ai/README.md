# 问阶 · AI文字面试交互预览

日期：2026-11-04。对应[PRD v0.4](../../PRD.md)、[AI功能调研](../../docs/11-ai-product-research.md)、[AI体验规格](../../docs/12-ai-experience.md)和[系统设计](../../docs/08-system-design.md)。A纸感编辑式，独立于[无模型核心原型](../core/index.html)、四版候选与旧原型。

## 打开与审阅

直接用普通浏览器打开[index.html](index.html)，无需安装依赖。页面只引用本目录的`ai.css`和`ai.js`，没有CDN、外部字体、模型或网络请求；CSP禁止网络连接。请只使用页面提供的合成回答，不输入真实履历、业务资料或密钥。

如既有本机预览服务可用，对应文件入口为 `http://127.0.0.1:8765/interview-studio/design/ai/index.html`。这不是当前服务可用或GUI已验收的声明；本轮不启动服务或改端口，实际结果见[就绪审查](../../docs/10-development-readiness.md)。

### 路径一：专项→评价→复练→对照

1. 准备页选择项目专项并勾选合成事实用途，或选择无材料基础题。
2. 点击“演示AI出题与采用”：看暂态题干、校验阶段和完整候选；采用题目／标准后开始。也可直接采用合成种子题，跳过出题演示。
3. 点击“填入合成原答”，再提交R1。提交不会自动评价、追问或结束。
4. 主动“演示获取本轮评价”：只有确切预设原答才展示对应预设候选；自写文本只保存并说明本页不分析，不套用固定诊断。
5. 在复盘页接受来源动作，或写说明保留争议／忽略。决定不改原候选，也不认证技术正确。
6. 回文字面试页，结束来源尝试；预览纳入修订、未答／跳过、未交草稿和在途任务，选择提交非空新稿后结束、仅纳入旧提交，或返回。
7. 复盘页从已接受行动开始空答新尝试，填合成新答、提交并结束；旧答仍是反馈对应的确切修订。
8. 对照页选择来源行动和已结束新答；可演示比较建议。用户另选结论、写理由，已处理／部分处理还要从新答复制完整唯一证据。只有用户保存已处理才关闭本来源，不表示技能掌握。

### 路径二：文字短模拟

选短模拟后固定3个主问题：基础→合成项目（未勾材料则无个人事实技术情景）→故障取舍。每主问至多1个合成追问，总计不超过6问，不计时。当前题先提交或按原因跳过，再推进主问题。过程中不展示提示、参考或本轮纠错；结束后主动生成合成复盘。

### 异常与版本演示

- 生成中可演示展示断线：本页定时任务可能继续；重连读取同task ID，不创建新生成。
- “演示缓冲重置”清暂态展示；完整结果就绪后再读，不保证补齐每个片段。
- 取消终止本页接纳；再次演示须明确新任务。真实供应商停算、退款与已发送字节召回均不保证。
- 下一次故障可选校验失败或发送／费用未知；不把未完整结果转成正式反馈，不显示未知费用为0。
- 生成追问／评价后提交R2、跳题、切换轮次或结束，旧实时任务代次失效；已成功旧反馈仍指R1。
- 追问完整生成后用户采用或丢弃；未采用候选不占正式题答轮次。追问明确新增假设，不把回调或接口保证当已知经历。

## 能力与简化边界

- **全部为固定合成内容、定时分段显示和本页内存；非真实AI／非SSE。**不会读取旧localStorage／IndexedDB／Cookie，不主动读文件，不接收密钥，不自动下载或上传。刷新／关闭清空，不能承诺恢复。
- 本页“提交”仅冻结内存快照，不是服务端持久化、CAS、权限或数据库保存。`demo-fnv32`不是SHA-256、安全校验或匿名化保证。
- 原文规范化CRLF为LF，拒绝孤立代理项，20,000 Unicode code points上限；证据使用完整原文code point半开区间，不能猜重复片段位置。实际Unicode与GUI仍需测试。
- 题目／标准、评价、追问及比较都预设。B01／P01来源于自拟样例，其他情景是本预览简化内容；均未获独立Java专家审核，不给确定技术对错、技术等级、录用率或精确总分。
- AI出题正式产品支持单次1–3题配置，本预览固定专项1题／模拟3题；没有任意题目生成、简历／JD解析、编辑题目候选或真实来源验证。事实用途只一个合成包，不是正式逐事实授权模型。
- 本页仅在完全匹配预设原答时展示预设检查方向；完全匹配合成新答时给示例说明，任意自写内容不作评价。它不是关键词判题或模型准确性验证。
- 默认一候选一行动。没有多来源显式合并、动作版本编辑、归档理由、变式生成界面、完整SelfCheckEntry对象、逐来源删除、导出、费用记账、服务端任务fencing或恢复账本。这些产品需求仍在PRD／系统文档，不能把本页简化计为已实现。
- 草稿切换轮次仍保本页输入；结束未交稿可只读查看，复盘只用提交修订。没有正式自动保存／双标签协议、离开保护或服务器恢复。
- 短模拟不计时／暂停、不录音／摄像；不宣称口语压力训练。活动模拟的前端隐藏不能替代正式服务端模式守卫或防作弊系统。
