# 问阶 · 知识银河

2026-11-04。独立可点击设计预览：把知识主题、个人笔记、项目事实、原答线索与主动回忆放进同一个知识空间。

## 查看

直接用浏览器打开本目录 `index.html`，无需安装依赖。也可运行 `node preview-server.cjs`，终端会输出本机预览地址；服务仅监听 `127.0.0.1`，端口由系统分配，只提供明确列出的静态文件。准备／训练入口在新标签打开现有核心原型。

## 可操作内容

- 六个主题星球、23 篇合成知识笔记组成同一张连续图谱，展示样例引用中实际存在的 34 组知识连接，支持缩放和平移。
- 主题聚焦保留全部节点及其位置；“聚焦关联”突出当前笔记及相邻知识，跨主题引用仍可见。虚线表示主题归属，实线表示知识引用。
- 知识列表、关键词筛选、无结果提示、星标、最近打开。
- 右侧知识详情：个人理解、引用／被引用、来源、项目原答线索。点击关联笔记同步图谱选中项、主题导航与下方探索路径。
- 回忆练习：独立输入、展开参考、自评、保留本页回答及回忆记录。再次打开未保存的回忆会恢复草稿。
- 新建个人笔记，归入主题并可进入回忆。用户文本按纯文本展示。
- 桌面、平板和手机布局；列表提供不依赖星图的内容入口；键盘支持搜索、视图切换及关闭弹窗。

## 能力边界

所有内容与初始待回忆状态均为合成示例，不代表真实经历或已确认的技术结论。参考要点未经独立专家审核。自评不等于掌握认证。

状态仅在当前页面内存中，刷新／关闭清空。没有账号、数据库、AI、Obsidian 文件库连接、自动调度或数据同步。“明天／3 天后”展示用户选择的回忆间隔，本页不创建后台提醒。当前页面不读取已有浏览器存储、不扫描文件，不发起远程请求。请使用演示内容。

星图为 Canvas 2D 星尘、DOM 行星与 SVG 连线，支持二维缩放与平移。知识关系采用明确的样例引用，不自动推导因果或熟练度。当前采用适合这批样例的固定布局，新笔记使用简单位置分配；尚未实现大规模图谱的自动布局。新笔记只显示主题归属，不自动生成知识引用。
