# 问阶 · 核心文字路径原型

日期：2026-11-04。此目录保留v0.3的无模型自检交互路径，作为内部可靠性设计与失败退路参考；当前产品范围见[PRD v0.4](../../PRD.md)、[系统设计](../../docs/08-system-design.md)，新的AI主线另见[AI文字预览](../ai/index.html)。两题种子见[内容样例](../../docs/09-content-samples.md)。全站A纸感编辑式，四候选和旧prototype均保留，不把此页预设追问／自检改名为AI。

## 打开与审阅

直接用普通浏览器打开[index.html](index.html)，无需安装或启动项目。HTML引用本目录 `core.css` 与 `core.js`，无CDN、外部字体或API。请勿填真实履历、业务材料、个人数据或密钥。

建议先走一次基础题，再走项目支路：

1. 基础题直达，不填JD／材料／模型；项目支路先选择合成事实并确认确切版本与责任。
2. 独立输入合成回答，提交成不可变R1；可显式补充R2，R1与已有自检仍保留。
3. 在只读提交原文选段并使用选区，或声明“未提及”绑定整回答；自己写缺口、动作与判断条件。
4. 保存用户自检，再主动接受动作。没有自动判断、自动接受或自动生成总评。
5. 显式结束来源尝试；未提交新草稿要选择如何处理，不能无声纳入。
6. 从来源行动新建尝试，新答案为空；独立提交并结束后做原答／新答／动作／条件对照。
7. 用户记录已处理／部分／未处理／无法判断；提交新答不会自动关闭行动，也不认定掌握技能。

页面另提供轻量目标／材料版本、自建题、题型筛选、练后笔记、历史、失败／冲突／旧ack、导出预览与本页删除演示。具体已覆盖和未覆盖行为以[本轮就绪审查](../../docs/10-development-readiness.md)为准；本说明不把静态事件绑定当作实际点击通过。

## 真正的能力边界

- **全部为合成设计数据和本页内存。**刷新／关闭会清空。不会访问用户旧localStorage／IndexedDB／Cookie，不主动读取用户文件或其他项目；仅在用户确认导出后通过Blob发起下载，不调用模型。
- 成功状态只表示本页内存快照，**不是服务端确认保存**。没有账号、数据库、CAS网络协议或真实异步服务器。
- 用户文本以DOM文本写入，不当HTML执行；CSP禁止网络连接。前端代码可被使用者修改，不能替代服务端授权、安全或并发保证。
- 回答引用用确切revision与完整原文的Unicode code point半开区间。`demo-fnv32`仅为演示校验码，不是系统设计要求的SHA-256，也不是安全／匿名化证明。
- B01／P01参考与追问是自拟预设，未经过独立专家复核。无标准自建题只能用户自检；不能把字数、关键词或“引用有效”当技术正确。
- 故障／冲突／旧回执都是手动、显式合成演示；真实网络、双标签CAS、旧worker、重启恢复和权限需正式工程测试。
- 导出只在预览、确认后用户点击发起本地Blob下载。下载是否完成仍需浏览器核验；释放Blob链接不能删除已下载文件。JSON／Markdown分别预览，不是正式系统的同一ZIP或恢复备份。
- 删除只清本页合成内存，必须先预览再确认；不触碰用户文件、已下载副本、旧浏览器数据、数据库或供应商。它不是正式系统完整lineage／备份清理的证明。
- 目标只是名称／关注点版本演示，不含正式JD原文／要求映射；材料是一个合成包，非逐事实正式模型。归档／撤用途／单来源删除、显式多来源合并、动作版本编辑、选范围导出未制作，不把这些需求算作已实现。
- 主答和项目预设追问可保存修订并选确切原文自检；争议／忽略决定与原自检分开。新答已处理／部分处理要求原文证据及理由，片段重复时需复制更长上下文；这些事件尚未实际运行核验。
- 计时／暂停、自由图编辑、语音、文件解析、多目标管理、模型／支付／公开服务均未接入。不为“看起来完整”显示虚假可用按钮。
