# 问阶 · 整合交互预览

2026-11-04。依据[完整版产品设计 v0.2](../../docs/14-full-product-blueprint.md)制作的独立交互原型。用于查看页面关系、视觉提案与代表性操作，不是正式应用工程。

## 打开方式

直接用浏览器打开 [index.html](index.html)，无需安装依赖。初始进入知识空间，左侧可切换今日、准备、知识、训练、复盘、成长。

也可以在 PowerShell 7 中，从本项目工作目录运行：

```powershell
node 'C:\AI\vibecoding\interview-studio\design\studio\preview-server.cjs'
if ($LASTEXITCODE -ne 0) { throw 'Preview server stopped with an error' }
```

终端打印本机预览地址，端口由系统分配。服务只监听 `127.0.0.1`，仅提供本目录的 HTML、CSS 和 JavaScript，不扫描或提供其他项目文件；这是临时预览进程，不设置开机启动或 Windows 服务。

## 推荐体验路径

1. **知识空间：**选择星图中的缓存一致性，切换主题、聚焦关联、缩放或拖动图谱；右侧查看主笔记与关联知识。窄屏也可使用知识点和主题下拉框。
2. **知识整理：**新建自由笔记或关联知识；切换到全部笔记编辑、暂存；白板卡片可拖动，卡片入口打开同一份源笔记。快捷键 `Ctrl K`／`⌘ K` 打开全局搜索。
3. **主动回忆：**先写自己的理解，再揭示笔记并自评；记录为临时练习，不调整常规复习排程。
4. **文字训练：**选择边学边练、独立专项或 3 题文字模拟，输入、提交、跳过、暂停和继续；同一页面内切换导航保留草稿。独立模式打开相关笔记或填入示例前，先明确转为辅助。
5. **复盘与复练：**查看原文及固定示例自检提示，点击提示定位原文，采用笔记候选或加入今日安排；独立复练从空白回答开始，完成后显示新旧对照并记录个人判断。
6. **准备与成长：**调整示例目标／职责状态，查看不同考察项的记录；回忆、自评、原答和比较结论分别显示。

## 视觉与内容边界

- 这版提出浅色工作台、松绿主色与深色银河；不是全站主题的最终决定。统一导航、按钮、保存状态和文字排版。
- 星图使用 **18 个合成知识点、6 个主题、26 组明确关系**，全部组成一个连续网络。知识点与笔记具有不同标识；主笔记展示同一份正文，普通关联笔记不会自动替换主笔记。
- 全部输入、收藏、笔记版本、草稿、回忆与训练记录只在**当前页面内存**，刷新／关闭还原。不得把“本页暂存”理解成服务端或浏览器持久化。
- 没有真实模型、费用、材料上传、账号、数据库、索引、Obsidian 同步、语音或后台复习调度。没有远程字体、脚本或图片依赖。
- 复盘是合成样例或固定自检清单，明确标注未调用 AI；原文区域展示实际提交文本。未提交草稿可展开查看，但不冒充已提交答案。
- 本版只演示核心交互。多主题编辑、批量关联、知识更正传播、归档删除、复杂导入、AI 授权任务与真正异常恢复仍以产品文档为设计要求，不因按钮或示例存在而声称实现。
- 此目录独立于旧 `knowledge-galaxy`／`core`／`ai` 原型，未覆盖它们的源码和验证记录。
