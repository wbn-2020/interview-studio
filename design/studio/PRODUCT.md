# 问阶 · 整合交互预览

## Register

product

## Platform

web

## Users

Java 后端求职者，在个人电脑上进行面试前准备、知识整理、文字训练和复盘。支持窄屏浏览核心文字流程。

## Product Purpose

以 [完整版业务设计 v0.2](../../docs/14-full-product-blueprint.md) 为依据，预览六个入口如何共享知识、训练与复练记录。用户本轮要求可点击、可交互的 UI 原型；不创建正式应用工程。

## Confirmed direction

知识独立于某一次训练和某个目标岗位；知识点汇聚笔记与训练证据；银河连续、主题切换保持位置。用户认可深色银河，不代表全站主题已确定。暂不做语音面试。

## Preview design choices

这版采用浅色阅读工作台、深色银河探索画布、松绿主色和一致的导航／控件。采用系统中文字体、固定字号、清晰保存状态，提供键盘操作、列表替代和减少动效支持。以上是本版视觉提案，不记为用户已逐项确认。

## Scope and evidence

本目录为独立 HTML／CSS／JavaScript 原型，全部内容为合成样例、全部交互状态仅在页面内存。真实模型、持久化、上传、自动调度和 Obsidian 同步不在本轮实现范围。示例反馈不得冒称实际 AI 评价。
