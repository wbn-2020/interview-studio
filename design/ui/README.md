## 比较原则

所有方向使用相同合成内容：Java后端·营销交易；3条已确认事实／1条待核实；“发奖超时结果未知”；原答“超时就补发”；扫码→资格→预算→发奖与状态／查单链路；追问依据图v1、当前草稿独立。不要把页面中的合成确认、历史或暂存误当用户真实数据。

- A：阅读主栏与边注证据，暖纸／青绿，适合长回答和资料。
- B：局部索引、编辑区与检查器并列，冷灰／工程蓝，适合高频对照。
- C：顶部导航、建议步骤与聚焦作答，轻绿训练室，适合首次准备。
- D：图与关系主导、面板停靠，冷中性／深青蓝，适合架构演练。

建议A全站，架构屏采用D的大画布与停靠结构。推荐不是用户已选择或视觉验收通过。

## 本页交互边界

共享的 `preview.js` 只操作当前页面DOM和内存，不访问网络、文件、Cookie或浏览器持久存储：

1. 切换准备、文字、白板；保留本页已经输入的文字。
2. 提交非空回答后原文回显并展开固定自检清单；使用文本写入，不将输入解释为HTML。
3. 节点选择改变预设追问，不调用AI；部分版本提供图示缩放，不是完整画布引擎。
4. “本页暂存”将合成节点／关系／约束、当前解释与选中项复制为本页内存快照并显示修订号，不承诺写入服务器；刷新／关闭会清空输入。
5. 打开只读合成历史，不替换当前草稿；关闭后继续编辑。
6. 本页复练按“回答R1”或“图v1＋节点”区分来源；只禁用相同来源的重复加入，其他来源仍可加入。不表示正式来源任务系统已实现。
7. 暂停演示保留输入并禁用提交；不模拟真实倒计时或服务器计时。
8. 未实现的材料／学习／设置通过说明呈现，不收集真实履历、文件、密钥或音频。

请勿在设计预览里输入私密材料。浏览器自身的扩展、恢复机制和自动填充不由本预览控制；本文件不主动持久保存输入。
